机器学习 · 世界模型Machine learning · World models

在脑子里试一试Try It in Your Head

推一个东西之前，人会先在脑子里过一遍：从这儿推，它会滑到哪儿；推得太猛，会不会冲过头。机器人能不能也这样，先在脑子里试一试，再动手？它需要一个"世界模型"：一个从数据里学出来、能回答"我这样做，接下来会怎样"的东西。这一篇从头到尾只用一个具体的任务：机器人用一根手指，把桌上的一个圆盘推进一个圈里（第 0 步先把这个任务说清楚）。从最简单的办法讲起，前四步，每一步都会撞上前一种办法的毛病，于是逼出下一种：推远了会跑偏，没见过的地方会乱说，只看得到画面时预测会发糊，压缩出来的东西又该装些什么。之后再看学好了怎么用，放大到视频以后有哪些新麻烦，它到底懂不懂物理。最后看机器人怎样用世界模型，再把几十种世界模型按不同的问题分组放在一起。Before pushing something, people first run through it in their heads: if I push from here, where will it slide to? If I push too hard, will it overshoot? Can a robot do the same: try it in its head first, then act? It needs a "world model": something learned from data that can answer "If I do this, what happens next?" From start to finish, this page uses one concrete task: a robot uses one finger to push a puck on a table into a ring (step 0 explains the task first). The page starts from the simplest approach, and for the first four steps each approach runs into a problem that forces the next one: drifting off when rolled out far, making things up in places it has never seen, blurry predictions when only images can be seen, and what the compressed version should contain. After that come how to use the model once it is learned, the new troubles that come with scaling up to video, and whether it really understands physics. Finally, it looks at how robots use world models, and puts dozens of world models side by side, grouped by different questions.

第 0 步 · 开场Step 0 · Opening

一个具体的任务：把圆盘推进圈里A concrete task: push the puck into the ring

整篇只用一个任务，先把它说清楚。桌上放着一个扁扁的圆形物块，像一枚大号的棋子，下面叫圆盘；桌面上还画着一个圈，叫目标。机器人要把圆盘推进圈里。它不去抓，只是推：机械臂末端装着一根竖直朝下的短杆，像一根手指，用它去拨圆盘。从上往下看，这根手指的横截面是一个圆，所以后面所有的俯视图里，手指都画成一个蓝色的圆，圆盘是橙色的圆。The whole page uses a single task, so first let us pin it down. On a table lies a flat, round object, like an oversized draughts piece, which we will call the puck; a ring drawn on the table is the goal. The robot has to push the puck into the ring. It does not grab it, it only pushes: at the end of the robot arm is a short rod pointing straight down, like a finger, and the robot nudges the puck with it. Seen from above, the finger’s cross-section is a circle, which is why in every top view from here on the finger is drawn as a blue circle, and the puck as an orange one.

为什么是推？桌上很多东西不好抓：太大、太扁、太滑，或者只是想挪一挪位置，推是最省事的办法。可推又最难算准：手指碰到圆盘的哪一点，决定圆盘往哪边走；手指停下以后，圆盘还会接着滑一段，滑多远取决于桌面的摩擦。所以"把东西推到指定的位置"一直是机器人学习里的常见考题：最早用学出来的视频预测模型给机器人做规划的工作之一，做的就是推东西（Finn & Levine 2017）；今天常用的 Push-T（把一个 T 形块推到指定的位置，Chi 等 2023）也是这一类，第 ④ 步的 DINO-WM 就拿它做实验。这里用最简单的版本：圆的手指推圆的圆盘。Why pushing? Many things on a table are hard to grasp: too big, too flat, too slippery, or you only want to shift them a little, and pushing is the simplest way. Yet pushing is also the hardest to calculate: the point where the finger touches the puck decides which way the puck goes, and once the finger stops, the puck slides on for a while, how far depending on the friction of the table. That is why "push an object to a given place" has long been a standard test in robot learning: one of the first works to plan a robot’s actions with a learned video prediction model was about pushing objects (Finn & Levine 2017), and today’s popular Push-T (pushing a T-shaped block to a given place, Chi et al. 2023) is of the same kind; DINO-WM in step ④ is tested on it. Here we use the simplest version: a round finger pushing a round puck.

机器人怎么动？它每 0.1 秒给手指发一个指令：往哪个方向、以多快的速度走，然后世界往前走 0.1 秒。这 0.1 秒叫一步，是整篇的时间单位；手指全速走一步是 2.5 cm。推一次，就是让手指朝同一个方向连续走若干步。上图最下面一栏就是推一次的分解：手指朝右走了 6 步（0.6 秒）后停下；圆盘被推着走，手指停下以后它又自己滑了一小段，到第 16 步才停住。How does the robot move? Every 0.1 s it sends the finger a command: which direction to move in and how fast, and then the world moves on by 0.1 s. These 0.1 s are called one step, the unit of time for the whole page; at full speed the finger moves 2.5 cm in one step. One push means letting the finger move several steps in a row in the same direction. The bottom panel of the figure above breaks one push down: the finger moves right for 6 steps (0.6 s) and stops; the puck is pushed along, and after the finger stops it slides on a little by itself, coming to rest only at step 16.

所以要解决的问题是：朝哪个方向推、推几步，圆盘才会停在圈里？如果机器人知道全部的物理规则（摩擦多大、碰撞怎么算），算一算就行。可它不知道，它只有过去随便推、随便走时录下的记录，得从这些记录里学出规律来。So the question to answer is: in which direction, and for how many steps, should the robot push so that the puck stops inside the ring? If the robot knew all the rules of physics (how much friction, how collisions work), it could simply calculate. But it does not; all it has are recordings made while it pushed and wandered about at random, and it has to learn the rules from them.

什么是世界模型What is a world model?

人推东西之前，会先在脑子里过一遍：从这边推，它大概会滑到哪；推得太猛，会不会冲过头。1943 年，心理学家 Kenneth Craik 就提出，人的脑子里装着一个外部世界的"小尺度模型"，可以先在里面试各种做法，挑出最好的再去做（Craik 1943）。机器人要这样做，需要一个能回答下面这个问题的东西：Before pushing something, people run through it in their heads: if I push from this side, where will it roughly slide to? If I push too hard, will it overshoot? In 1943 the psychologist Kenneth Craik proposed that people carry in their heads a "small-scale model" of the outside world, in which they can first try out different courses of action and pick the best before acting (Craik 1943). For a robot to do this, it needs something that can answer the following question:

st+1 ≈ f(st, at)

现在的状态是 st，这一步发出的指令是 at，0.1 秒后的状态大概是 st+1。The state now is st, the command sent at this step is at, and the state 0.1 s later is roughly st+1.

只问"下一步"，因为再远的未来也可以一步一步接着问：把预测出来的下一步当成新的"现在"，再问一次，就能往前推任意多步，推一次要走几步就问几次。世界本身也是这样一步一步走的：只要"这一刻"记全了要紧的东西（位置，还有速度），下一刻就只取决于这一刻和这一刻做了什么。所以状态里要放圆盘的速度；只看一张画面时，这一条就不成立了（第 ③ 步）。Only the "next step" is asked about, because any more distant future can be reached by asking again, one step at a time: treat the predicted next step as the new "now", ask again, and you can roll forward as many steps as you like: for a push of n steps, ask n times. The world itself also moves one step at a time: as long as "this moment" records everything that matters (positions, and velocities too), the next moment depends only on this moment and on what is done in it. That is why the state includes the puck’s velocity; with only a single image to look at, this no longer holds (step ③).

世界模型：从记录里学出来的函数The world model: a function learned from the recordings

一个"如果……会怎样"的机器：告诉它现在的样子和你的打算，它告诉你接下来的样子。A "what if" machine: tell it how things are now and what you intend to do, and it tells you how things will be next.

手指贴在圆盘左边，指令 a = (1, 0)，即全速往右。真实世界里，0.1 秒后手指往右走了 2.5 cm，把圆盘也推着走了 2.5 cm。一个好的世界模型给出的应该是差不多的数。The finger is touching the left side of the puck, and the command is a = (1, 0), i.e. full speed to the right. In the real world, 0.1 s later the finger has moved 2.5 cm to the right, pushing the puck 2.5 cm along with it. A good world model should give roughly the same numbers.

f 不一定是一个确定的函数。同一个开头、同一个指令，未来可能不止一种（桌面有多滑？会不会有人碰它？），这时 f 要给出的是一个分布，第 ③ 步会专门讲。f need not be a deterministic function. From the same start with the same command there may be more than one possible future (how slippery is the table? will someone bump it?); then f has to give a distribution. Step ③ deals with this in detail.

这个 f 有几个近亲，要先分清：This f has a few close relatives, which should be told apart first:

  • 仿真器（MuJoCo、Isaac 这类物理引擎）回答的是同一个问题，但规则是人写进去的：质量、摩擦、碰撞，一条一条编好。世界模型的规则是从数据里学出来的，不需要谁先把物理写清楚；代价是数据没覆盖到的地方，它会乱说。Simulators (physics engines such as MuJoCo and Isaac) answer the same question, but their rules are written in by people: mass, friction and collisions, coded up one rule at a time. A world model’s rules are learned from data, so nobody has to spell out the physics first; the price is that where the data do not reach, it makes things up.
  • 视频生成模型（上一篇讲的扩散、Flow Matching 都能生成视频）预测"接下来的画面像什么样"，但通常不管你做了什么。世界模型必须听动作：同一个开头，手指往左推和往右推，未来应该不一样。第 ⑥ 步会讲怎样让视频模型听动作。Video generation models (diffusion and flow matching, covered on the previous page, can both generate video) predict "what the coming frames will look like", but usually ignore what you do. A world model has to respond to actions: from the same start, pushing left and pushing right should lead to different futures. Step ⑥ shows how to make a video model respond to actions.
  • 控制里的模型：第六篇第 ⑨ 步讲过，MPC（模型预测控制）公式里的那个 f 就是一个模型，从数据里学出来的 f 就是世界模型；那一步用一个摆杆看了模型可以放在哪、可以拿来干什么。这一篇换一个难得多的例子，把世界模型本身拆开来看。The model in control: as step ⑨ of page 6 explained, the f in the MPC (model predictive control) formula is a model, and an f learned from data is a world model; that step used a pendulum arm to look at where a model can sit and what it can be used for. This page switches to a much harder example and takes the world model itself apart.

为什么要先在脑子里试？在真实世界里试一次很贵：要花时间，会磨损，推错了还收不回来；对机器人来说，一次失败可能是摔一跤，或者打碎一个杯子。在模型里试一次几乎不花钱，还可以同时试几千种、试完再挑。只要模型够准，在模型里挑出来的好办法，在真实世界里也是好的。整篇都围着"够准"打转：怎样学，才能让它够准；不够准的时候，怎样才不被它骗。Why try it in your head first? A single try in the real world is expensive: it takes time, it causes wear, and a wrong push cannot be undone; for a robot, one failure might mean a fall or a broken cup. A try in the model costs almost nothing, and thousands of options can be tried at once, with the best picked afterwards. As long as the model is accurate enough, a good option picked in the model is also good in the real world. The whole page revolves around "accurate enough": how to learn a model so that it is accurate enough, and how not to be fooled by it when it is not.

第 ① 步 · 最简单Step ① · The simplest

读得到状态，就学"下一步"If the state can be read, learn the "next step"

先假设最好的情况：机器人能直接读到状态 s，也就是手指和圆盘的位置、圆盘的速度，一共 6 个数。那世界模型就是一个普通的回归问题：输入现在的 6 个数和动作的 2 个数，输出下一步手指和圆盘的位置（4 个数）；圆盘的速度不用另学，直接用"这一步走了多远 ÷ 0.1 秒"算出来。Start by assuming the best case: the robot can read the state s directly, that is, the positions of the finger and the puck and the puck’s velocity, 6 numbers in all. The world model is then an ordinary regression problem: the input is the 6 numbers for now plus the 2 numbers of the action, and the output is the positions of the finger and the puck at the next step (4 numbers); the puck’s velocity need not be learned separately, since it is simply "how far it moved this step ÷ 0.1 s".

数据从"玩耍"里来：让手指随便推一阵、走一阵，记下每一步的（现在，动作，下一步）。这里一共收了 10 万步，按每步 0.1 秒算，相当于真机上推了将近 3 个小时。模型是一个两层、每层 64 个神经元的小网络，一共 5124 个参数。The data come from "play": the finger pushes for a while and wanders for a while at random, and (now, action, next) is recorded at every step. In all, 100 000 steps were collected here; at 0.1 s per step, that is nearly 3 hours of pushing on a real machine. The model is a small network with two layers of 64 neurons each, 5 124 parameters in all.

在所有记下来的（现在，动作，下一步）上，让模型的预测和真实的下一步尽量接近，用差的平方的平均来衡量。Over all the recorded (now, action, next) triples, make the model’s prediction as close as possible to the real next step, measuring closeness by the mean of the squared differences.

这就是最普通的回归。实际训练时有两个小窍门。一是让网络预测"变化量" st+1 − st，而不是 st+1 本身：大多数时候东西只动一点点，变化量更好学。二是把输入换成更好学的形式：推不推得着，只取决于手指和圆盘挨得多近，所以除了各自的位置，还把"手指相对圆盘在哪"直接喂给网络。This is regression of the most ordinary kind. In practice, training uses two small tricks. First, the network predicts the "change" st+1 − st rather than st+1 itself: most of the time things move only a little, and the change is easier to learn. Second, the input is recast in a form that is easier to learn from: whether a push moves the puck at all depends only on how close the finger and the puck are, so besides their separate positions, "where the finger is relative to the puck" is fed to the network directly.

用 1 万步数据训练的模型，预测一步，圆盘的位置平均只差 1.9 mm；手指全速走一步是 25 mm，误差不到一成。用 1000 步数据是 4.2 mm，用 10 万步是 1.4 mm。The model trained on 10 000 steps of data predicts the puck’s position one step ahead with an average error of only 1.9 mm; a full-speed finger step is 25 mm, so the error is under a tenth of that. With 1 000 steps of data it is 4.2 mm, and with 100 000 steps 1.4 mm.

训练时，模型的输入永远是真实的状态。用的时候不是这样：往前想第二步，输入就是它自己上一步的预测，带着误差。它从来没在"带误差的输入"上练过。In training, the model’s input is always a real state. In use it is not: when imagining the second step ahead, the input is its own prediction from the step before, error and all. It has never practised on "inputs with errors".

一步准，不等于多步准。规划要往前想很多步：从现在出发，用模型预测下一步，再把这个预测当成现在，接着预测下一步……这叫开环推演，也就是"想象"：中途不再看真实世界，只看自己的预测。每一步的小错，都会被下一步当成真的，接着往下算。Accurate for one step does not mean accurate for many. Planning has to imagine many steps ahead: start from now, use the model to predict the next step, then treat that prediction as now and predict the next step again… This is called an open-loop rollout, or "imagining": along the way it no longer looks at the real world, only at its own predictions. Each step’s small error is taken as true by the next step and carried on into the calculation.

想象走到第 t+1 步时偏了多少 = 上一步已经偏的，被这一步放大或缩小 Jt 倍，再加上这一步自己新犯的错。How far off the imagination is at step t+1 = how far off it already was at the previous step, scaled up or down by a factor Jt at this step, plus the new error made at this step.

模型把上一步的预测当成真的接着算，上一步偏了多少，就带着多少进入这一步，再经过这一步的"变化规则"：Jt 就是"输入差一点，输出会差多少"的倍数（数学上叫雅可比矩阵）。一路展开，往前想到第 H 步（H 就是往前想的步数）时，偏差是前面每一步新错误的叠加，越早犯的错，被乘了越多次 J。The model takes its previous prediction as true and carries on from it, so whatever error the previous step had is carried into this step and then passes through this step’s "rule of change": Jt is the factor that says "if the input is off by a little, how much will the output be off" (mathematically, the Jacobian matrix). Unrolled all the way, the error after imagining H steps ahead (H is the number of steps imagined) is the sum of the new errors made at every earlier step, and the earlier an error was made, the more times it has been multiplied by J.

如果 J 不放大，50 步的偏差最多是 50 个一步误差叠起来：50 × 1.9 mm ≈ 9.5 cm（每步都错在同一个方向才会这么大）。实测是 14 cm，超过了这个上限：一是有些地方误差在被放大；二是输入带着误差，每一步新犯的错也比 1.9 mm 大（上面的要点说过，它没在带误差的输入上练过）。If J did not amplify anything, the error after 50 steps would be at most 50 one-step errors stacked up: 50 × 1.9 mm ≈ 9.5 cm (and only that large if every step erred in the same direction). The measured error is 14 cm, above this ceiling, for two reasons: in some places the error is being amplified; and with errors in its input, each new error is also bigger than 1.9 mm (as the key point above said, the model was never trained on inputs that carry errors).

推东西时，Jt 在接触的那一刻特别大：手指擦着圆盘边缘时，差一毫米就是"推到了"和"没推到"的区别；就算推到了，打在哪儿也决定了圆盘往哪边偏。接触偏偏就是推圆盘这件事的全部。When pushing things, Jt is especially large at the moment of contact: when the finger grazes the edge of the puck, a millimetre is the difference between "hit it" and "missed it"; and even when it does hit, where it strikes decides which way the puck veers. And contact is exactly what pushing a puck is all about.

对付它，有几种常见的办法：There are a few common ways of dealing with it:

  • 想完只走一步。每走一步都用真实状态重新开始想。这正是 MPC 的做法（第 ⑤ 步）：往前想十几步（第 ⑤ 步的交互里是 12 步），只执行第一步，看清真实世界变成什么样，再从头想。远处想得不准，只会让这一步挑得差一点，不会一路错下去。Take one step, then think again. After every step, start imagining afresh from the real state. This is exactly what MPC does (step ⑤): imagine a dozen or so steps ahead (12 in the interactive of step ⑤), carry out only the first, see what the real world has become, and think again from scratch. Imagining the far future badly then only makes this one step a slightly worse choice; it does not send you off course all the way.
  • 训练时就让它吃自己的预测。不只训练一步，而是把模型往前滚几步，对每一步的偏差都罚分；或者把它自己预测出的状态当成新的输入、配上真实的下一步，再训练一遍（Talvitie 2014；Venkatraman 等 2015）。它就学会了从"有点偏"的地方往回拉。Feed it its own predictions during training. Instead of training on single steps only, roll the model forward a few steps and penalise the error at every step; or take the states it has predicted itself, use them as new inputs paired with the real next steps, and train again (Talvitie 2014; Venkatraman et al. 2015). It then learns to pull itself back from places that are "a little off".
  • 换一个更好预测的空间。第 ③、④ 步会讲：不在原始的数里预测，而在压缩过的空间里预测。Switch to a space where prediction is easier. Steps ③ and ④ explain this: predict not in the raw numbers but in a compressed space.

这条路早就有人走通了：PILCO（Deisenroth & Rasmussen 2011）用高斯过程（一种回归方法，预测时顺带说出自己有多没把握）学模型，在真实的小车倒立摆上，只用了 17.5 秒的交互就学会把摆甩上去并稳住；Nagabandi 等 2018 用神经网络学模型、再配上 MPC，让模拟的腿式机器人用比无模型强化学习（不学世界模型、直接靠大量试错学动作，第三篇讲过）少得多的数据学会了跑。可是比误差积累更危险的，是下一步要讲的事：规划器会主动去找模型错的地方。People got this approach working long ago: PILCO (Deisenroth & Rasmussen 2011) used Gaussian processes (a regression method that also says how unsure it is of each prediction) to learn a model and, on a real cart-pole, learned to swing the pole up and balance it with only 17.5 s of interaction; Nagabandi et al. 2018 used a neural network to learn a model and paired it with MPC, so that simulated legged robots learned to run with far less data than model-free reinforcement learning (which learns no world model and learns actions directly by trial and error on a large scale; page 3 covered it) needs. But more dangerous than compounding error is the subject of the next step: the planner actively seeks out the places where the model is wrong.

第 ② 步 · 不确定Step ② · Uncertainty

没见过的地方，它会自信地乱说In places it has never seen, it talks nonsense with confidence

模型只在数据覆盖到的地方可信。到了数据之外，网络照样给出一个数，而且从不说"我不知道"。这本身还不算最糟。最糟的是，规划器会专门去找这些地方：它在模型里试了成百上千种动作，挑出"想象中效果最好"的那一个；如果模型在某个没见过的地方错误地以为效果特别好，规划器就正好会挑中它。这叫模型被钻空子（model exploitation），就像判卷老师有几道题总会判错，考生专挑这几道去答：分数很高，真本事没有。A model can be trusted only where its data reach. Outside the data, the network still gives a number, and it never says "I don’t know". That on its own is not the worst of it. The worst is that the planner goes looking for exactly these places: it tries hundreds or thousands of actions in the model and picks the one that does "best in imagination"; if, somewhere it has never seen, the model wrongly believes an action works especially well, that is precisely the one the planner will pick. This is called model exploitation. It is like an examiner who always marks a few particular questions wrongly, and a candidate who answers only those: high marks, no real skill.

把问题缩到最小来看。手指贴着圆盘，用力度 u 往右推一下（u 是手指速度占全速的比例，从 0 到 1；推 6 步，然后停下），看圆盘滑出去多远。真实的关系是：力度 0.2 时滑 3.3 cm，0.5 时滑 9.0 cm，0.8 时滑 14.6 cm，用足全力（u = 1）也只能滑 18.3 cm。可模型一开始只见过轻推：8 条数据，力度都在 0.1 到 0.45 之间。现在要把圆盘推到 16 cm 远，就得用它从没见过的力度。Shrink the problem to its smallest form. The finger, touching the puck, gives it one push to the right with strength u (u is the finger’s speed as a fraction of full speed, from 0 to 1; it pushes for 6 steps, then stops), and we look at how far the puck slides. The true relation: at strength 0.2 it slides 3.3 cm, at 0.5 it slides 9.0 cm, at 0.8 it slides 14.6 cm, and even at full strength (u = 1) it slides only 18.3 cm. But at first the model has seen only gentle pushes: 8 data points, all with strengths between 0.1 and 0.45. Pushing the puck 16 cm now takes a strength it has never seen.

办法是不只训练一个模型，而是训练好几个：The fix is to train not one model but several:

μ(a) = (1/K) Σk fk(a), σ(a) = √[ (1/K) Σk (fk(a) − μ(a))² ]

K 个模型对同一个动作的预测，取平均是 μ，看它们彼此差多少是 σ。For the same action, the average of the K models’ predictions is μ, and how much they differ from one another is σ.

几个模型用同样的数据训练，只是起点（随机初始化）不同，或者各自用数据的一个随机重抽样。在数据多的地方，它们都被数据"按住"了，说法一致；在没有数据的地方，各自按自己的方式往外猜，猜法不同。所以分歧 σ 大，就说明这里数据少，别太当真；反过来却不一定：几个模型也可能一起错。这叫集成（ensemble，Lakshminarayanan 等 2017）。The models are trained on the same data and differ only in their starting point (the random initialisation); or each one is trained on its own random resample of the data. Where data are plentiful, they are all "pinned down" by the data and agree; where there are no data, each extrapolates in its own way, and their guesses differ. So a large disagreement σ means data are scarce here, and the prediction should not be taken too seriously; the converse does not hold, though: several models can also be wrong together. This is called an ensemble (Lakshminarayanan et al. 2017).

分歧量的只是"没见过"带来的不确定，叫认知不确定性：数据多了，它就会消失。还有一种不确定来自世界本身：比如这张桌子有多滑，光看眼前这一帧看不出来，收再多的训练数据也消不掉，叫偶然不确定性。两种要分开对待：前者值得去多收数据；后者要让模型老老实实说出"可能这样、也可能那样"，能多看几眼的话，再从过去的画面里把它推出来（第 ③ 步）。The disagreement measures only the uncertainty that comes from "never having seen it", which is called epistemic uncertainty: with more data, it disappears. Another kind of uncertainty comes from the world itself: how slippery this particular table is, for example, cannot be seen from the frame in front of you, and no amount of training data removes it; it is called aleatoric uncertainty. The two should be treated differently: the first is worth collecting more data for; for the second, the model should honestly say "it might be this, or it might be that", and if it can take a few more looks, work it out from the past frames (step ③).

知道了哪里没把握，挑动作时就可以把它算进去，有几种态度：Once you know where the model is unsure, you can take that into account when choosing actions. There are a few attitudes you can take:

  • 悲观：挑动作时把分歧当成代价加上去，比如让 |μ − 目标| + σ 最小。宁可选一个大家都有把握、效果稍差一点的动作。只有一批旧数据、不能再去试的时候（离线强化学习），基于模型的方法常常这样做（MOPO，Yu 等 2020）。Pessimistic: when choosing an action, add the disagreement as a cost, for example by minimising |μ − goal| + σ. Better to pick an action that all the models are sure of, even if it works a little less well. When there is only a batch of old data and no way to go and try again (offline reinforcement learning), model-based methods often do this (MOPO, Yu et al. 2020).
  • 乐观：反过来，把分歧当成奖励，专去模型最没把握的地方试。试一次学到的东西最多，适合探索（Plan2Explore，Sekar 等 2020 就靠分歧来决定去哪儿探索）。Optimistic: the other way round. Treat the disagreement as a reward and go out of your way to try where the model is least sure. That is where one try teaches the most, so it suits exploration (Plan2Explore, Sekar et al. 2020 uses disagreement to decide where to explore).
  • 只推几步：想得越远，越容易走到没见过的地方。MBPO（Janner 等 2019）只从真实见过的状态出发，在模型里推很短的几步，用这些短的想象去训练策略（一个看到状态就直接给出动作的网络，第 ⑤ 步细讲）。Roll out only a few steps: the further ahead you imagine, the more likely you are to wander into places the model has never seen. MBPO (Janner et al. 2019) starts only from states that have really been seen, rolls out just a few steps in the model, and uses these short stretches of imagination to train the policy (a network that looks at the state and gives an action directly; step ⑤ covers it in detail).
  • 把集成直接用进规划：PETS（Chua 等 2018）用 5 个模型，每个模型还输出一个高斯（同时表达世界本身的随机）；规划时每条想象的路线随机换着用不同的模型推，好动作必须在几个模型里都好。Use the ensemble directly in planning: PETS (Chua et al. 2018) uses 5 models, each of which also outputs a Gaussian (to capture the randomness of the world itself as well); during planning, each imagined path is rolled out by switching between the models at random, so a good action has to be good in several models.

"试一次"这个按钮，就是基于模型的强化学习（MBRL）的一圈：收数据，学模型，在模型里挑动作，真去做，新数据加回来，再学模型。强化学习里最早把这一圈写清楚的，是 Dyna（Sutton 1990）。不确定性决定了下一圈去哪儿收数据：数据会自己长到最需要它的地方。The "Try once" button is one turn of the loop of model-based reinforcement learning (MBRL): collect data, learn a model, choose an action in the model, do it for real, add the new data, learn the model again. In reinforcement learning, the first to set this loop out clearly was Dyna (Sutton 1990). Uncertainty decides where the next turn collects data: the data grow by themselves where they are needed most.

到这里为止，我们都假设机器人能直接读到状态：手指在哪、圆盘在哪、圆盘多快。真实的机器人知道自己的手在哪（关节上有编码器），可桌上的东西在哪、滑得多快，没有现成的清单，只能靠相机看。So far we have assumed that the robot can read the state directly: where the finger is, where the puck is, how fast the puck is moving. A real robot knows where its own hand is (its joints have encoders), but where the things on the table are and how fast they are sliding come with no ready-made list; it can only look with a camera.

只看得到画面时When all it can see is images

相机给的是画面。一张 32 × 32 的灰度俯视图就是 1024 个数，真实相机的一帧则是几百万个数。最直接的办法，是把第 ① 步原样搬过来：输入这一帧和动作，输出下一帧，用每个像素的均方误差来训练。这会撞上两个新问题。A camera gives images. A 32 × 32 greyscale top view is 1 024 numbers, and one frame from a real camera is several million. The most direct approach is to carry step ① over unchanged: input this frame and the action, output the next frame, and train with the mean squared error over every pixel. This runs into two new problems.

第一个问题：未来不止一种时，预测会发糊。同一个画面里，往往藏着看不见的东西。比如桌面有多滑（这一步换成摩擦不定的桌子：前面那张桌子每步都保留 60% 的速度，这里每张都不一样）：手指推着圆盘走的时候，滑和不滑的桌子画面完全一样；手指一停，圆盘在滑的桌子上能滑出去 25 cm，在涩的桌子上只滑 1 cm。模型看到的画面一样，正确的未来却有很多种。按均方误差训练，它会给出什么？The first problem: when there is more than one possible future, the prediction blurs. A single image often hides things you cannot see. Take how slippery the table is (from this step on, the table’s friction is unknown: the earlier table kept 60% of the puck’s speed at every step, but here every table is different): while the finger is pushing the puck along, a slippery table and a non-slippery one give exactly the same images; once the finger stops, the puck can slide 25 cm on a slippery table but only 1 cm on a rough one. The model sees the same images, yet there are many correct futures. Trained with mean squared error, what will it predict?

argminô E[ ‖o − ô‖² ] = E[ o ]

要让"平均下来的平方误差"最小，最好的预测就是所有可能未来的平均。The prediction that makes the "average squared error" smallest is the average of all the possible futures.

把误差拆开：E‖o − ô‖² = ‖E[o] − ô‖² + E‖o − E[o]‖²（中间的交叉项平均下来是 0，因为 o − E[o] 平均是 0）。第二项是未来本身有多分散，和预测无关；第一项在 ô = E[o] 时为 0。所以不管网络多大、训练多久，只要用均方误差，它学到的就是平均。上一篇第 0 步说过同一件事：好几个都对的答案，它们的平均往往一个都不是。Break the error into two parts: E‖o − ô‖² = ‖E[o] − ô‖² + E‖o − E[o]‖² (the cross term in between averages to 0, because o − E[o] averages to 0). The second term is how spread out the future itself is, and does not depend on the prediction; the first term is 0 when ô = E[o]. So however large the network and however long it is trained, as long as it uses mean squared error, what it learns is the average. Step 0 of the previous page made the same point: when several answers are all right, their average is often none of them.

交互里，滑多远的 25 种可能一样大的时候，"糊成一条"的那张图，平均像素误差是 28.2；从中抽一种可能、画一个清楚的圆盘，平均误差是 56.3，几乎正好两倍（差的 0.1 来自四舍五入）。这不是巧合：抽出来的那张图本身就是一种可能的未来，真实的未来是另一种，两者互不相干；两个互不相干的未来之间"差的平方"的平均，总是每个未来"离平均的差的平方"的平均的两倍。In the interactive, when the 25 possible slide distances are all equally likely, the picture "smeared into a streak" has a mean pixel error of 28.2; sampling one of the possibilities and drawing one sharp puck gives a mean error of 56.3, almost exactly twice as much (the 0.1 gap comes from rounding). This is no coincidence: the sampled picture is itself one possible future, the real future is another, and the two have nothing to do with each other; for two such independent futures, the average of their "squared difference" is always twice the average "squared difference from the average" of each one.

所以"误差小"和"画得像"是两回事。按均方误差打分，糊的预测永远赢；可规划要的不是一张谁都不像的平均图，而是"可能会这样，也可能会那样"。So "small error" and "a good likeness" are two different things. Scored by squared error, the blurry prediction always wins; but what planning needs is not an average picture that looks like none of the futures, but "it might go this way, or it might go that way".

第二个问题：一帧画面不够。单看一帧，看不出圆盘在往哪滑、滑得多快，更看不出桌面有多滑。这些都得从前面几帧里推出来：模型需要记忆。The second problem: one frame is not enough. From a single frame you cannot tell which way the puck is sliding or how fast, let alone how slippery the table is. All of this has to be worked out from the previous few frames: the model needs memory.

解法有三件事：先把画面压缩成一小串数，在这个小空间里预测要容易得多（压缩出来的那一小串数叫潜变量，它们所在的空间叫潜空间）；对说不准的部分抽签，而不是取平均（治发糊）；再加一个一步步往下传的记忆（治一帧不够）。World Models（Ha & Schmidhuber 2018）拿赛车和《毁灭战士》这类电子游戏做例子，把这些做成了三块：用一个 VAE（上一篇第 ③ 步）把每一帧压成一小串数 z；用一个循环网络记住过去，并预测下一个 z 的分布（一个混合高斯，用来表达"可能这样、也可能那样"）；最后一个很小的控制器只看 z 和记忆来出动作。控制器甚至可以完全在这个模型的"梦"里训练，再拿到真的游戏里用。The answer has three parts: compress the picture into a short list of numbers, where prediction is much easier (that short list of numbers is called a latent variable, and the space it lives in the latent space); draw lots for whatever cannot be known, instead of averaging (this cures the blur); and add a memory that is passed along step by step (this cures "one frame is not enough"). World Models (Ha & Schmidhuber 2018), using video games such as car racing and Doom as examples, built this from three parts: a VAE (step ③ of the previous page) squeezes each frame into a short list of numbers z; a recurrent network remembers the past and predicts the distribution of the next z (a mixture of Gaussians, to express "it might be this, or it might be that"); and finally a very small controller looks only at z and the memory to produce the action. The controller can even be trained entirely inside this model’s "dream" and then used in the real game.

PlaNet（Hafner 等 2019）把记忆和随机分得更清楚，提出了后来一直沿用的循环状态空间模型（RSSM）：PlaNet (Hafner et al. 2019) separated memory and randomness more cleanly and introduced the recurrent state-space model (RSSM), which has been used ever since:

ht = f(ht−1, zt−1, at−1), zt ∼ p(zt | ht), zt ∼ q(zt | ht, ot), ôt = g(ht, zt)

记忆 h 一步一步确定地往下传；这一刻还不确定的部分 z 是抽出来的：没看到画面时，凭记忆去猜（先验 p，公式的第二项）；看到了画面，就用画面来纠正（后验 q，第三项）。从 h 和 z 可以画出这一帧。The memory h is passed on deterministically, step by step; z, the part that is still uncertain at this moment, is sampled: with no frame to look at, it is guessed from memory (the prior p, the second term of the formula); once a frame is seen, the frame is used to correct it (the posterior q, the third term). From h and z, the model can draw the frame.

只有确定的 h，遇到"可能这样、也可能那样"的未来，只能取平均，又糊了；只有随机的 z，又记不住过去。所以两条路并行：h 负责记，z 负责抽签。训练用的正是上一篇第 ③ 步 VAE 的证据下界：把画面画回来（重建），预测奖励（每一步做得好不好的一个分数，比如圆盘离目标近了就加分），再加一项 KL(q ‖ p)（KL 散度：两个分布差多远，上一篇第 ③ 步用过），逼着"没看画面时的猜测"去追"看了画面后的判断"。With only a deterministic h, a future that "might be this, might be that" can only be averaged, and the prediction blurs again; with only a random z, the past cannot be remembered. So two paths run in parallel: h takes care of remembering, z of drawing lots. Training uses exactly the VAE’s evidence lower bound (ELBO) from step ③ of the previous page: redraw the image (reconstruction), predict the reward (a score for how well each step went; for example, points for getting the puck closer to the goal), and add a term KL(q ‖ p) (the KL divergence: how far apart two distributions are, used in step ③ of the previous page) that forces "the guess made without seeing the frame" to chase "the judgement made after seeing it".

第 ④ 步 · 潜空间Step ④ · Latent space

潜空间里该装什么What belongs in the latent space

压缩是对的：在几十个数里预测，比在几百万个像素里预测容易得多。可压缩成的那一小串数 z，装的应该是什么？Dreamer 的回答是"能把画面画回来的东西"。这听起来天经地义，其实有个毛病：画面里最占地方的，不一定最要紧。Compression is the right idea: predicting a few dozen numbers is far easier than predicting millions of pixels. But what should that short string of numbers, z, actually hold? Dreamer’s answer is "whatever it takes to redraw the picture". That sounds obviously right, but it has a flaw: what takes up the most room in the picture is not necessarily what matters most.

想象机器人在推圆盘，背景里有一台开着的电视，或者窗外的树叶在晃。要把画面画回来，z 就得记住电视在放什么、每片树叶在哪；可这些和推圆盘毫无关系。反过来，要紧的东西可能只占几个像素：打乒乓球的游戏里，球只有两三个像素那么大，最小化像素误差的模型很容易把它丢掉。z 只有那么几个数，被没用的东西占了，有用的就装不下。Imagine the robot pushing the puck with a television switched on in the background, or with the leaves outside the window swaying. To redraw the picture, z has to remember what is on the television and where every leaf is, yet none of this has anything to do with pushing the puck. Conversely, what matters may take up only a few pixels: in a table-tennis video game the ball is just two or three pixels across, and a model that minimises pixel error can easily lose it. With only a few numbers in z, if useless things take them up, there is no room left for the useful ones.

于是有了另外两种回答：That led to two other answers:

  • 只装预测价值需要的东西。MuZero（Schrittwieser 等 2019）从不把画面画回来。它的潜状态只被要求预测三样东西：奖励、价值（从这里往后还能拿多少分）、该走哪一步。只要这三样预测得对，潜状态里装了什么都行（价值等价原则，Grimm 等 2020）。它在围棋、国际象棋、将棋和 Atari 上都达到了顶尖水平，而且事先不知道这些游戏的规则。Keep only what is needed to predict value. MuZero (Schrittwieser et al. 2019) never redraws the picture. Its latent state is asked to predict only three things: the reward, the value (how many more points can be won from here on) and which move to make. As long as these three are predicted correctly, the latent state may hold anything at all (the value equivalence principle, Grimm et al. 2020). It reached the top level in Go, chess, shogi and Atari games, without being told the rules of any of these games in advance.
  • 在表示空间里预测。不预测下一帧的像素，而是预测"下一帧被编码以后是什么"。这里的"表示"也是编码器给出的一小串数，和潜变量是一类东西；不同的是它不用画回画面，只要求能拿来预测。这就是 LeCun 提出的联合嵌入预测架构（JEPA，LeCun 2022）：编码器自己决定哪些细节值得编进去，没法预测的细节（树叶怎么晃）可以干脆不编。Predict in representation space. Instead of predicting the pixels of the next frame, predict "what the next frame becomes once it is encoded". The "representation" here is also a short list of numbers produced by an encoder, the same kind of thing as a latent variable; the difference is that it never has to redraw the picture, only to be useful for prediction. This is the joint-embedding predictive architecture proposed by LeCun (JEPA, LeCun 2022): the encoder decides for itself which details are worth encoding, and details that cannot be predicted (how the leaves sway) can simply be left out.
L = ‖ P(zt, at) − sg( z̄t+1 ) ‖², zt = E(ot), z̄t+1 = Ē(ot+1)

把这一帧编码成 zt，再用一个预测器 P 从 zt 和动作猜出下一帧的编码；"答案"是用编码器 Ē 把真实的下一帧编码出来的 z̄t+1。Encode this frame as zt, then use a predictor P to guess the next frame’s encoding from zt and the action; the "answer" is z̄t+1, the encoding of the real next frame produced by the encoder Ē.

和第 ① 步的回归一模一样，只是把"下一步的状态"换成了"下一帧的编码"。答案也是网络自己算出来的：要是梯度也能流进答案那一侧，网络就会去挪"答案"来迁就预测，两边一起缩成同一个数最省事。所以在它外面套一个 sg：训练时把答案当作常数，梯度只从预测那一侧回传（光有 sg 还挡不住坍塌，下面会看到）。Ē 可以就是 E 本身，也可以是 E 的一个慢慢跟上的副本（每一步只朝 E 挪一点点，叫指数滑动平均，EMA）。This is exactly the regression of step ①, with "the next state" replaced by "the next frame’s encoding". The answer, too, is computed by the network itself: if the gradient could also flow into the answer side, the network would move the "answer" to suit the prediction, and the easiest way out is for both sides to shrink to the same number. So the answer is wrapped in an sg: during training it is treated as a constant, and the gradient flows back only through the prediction side (sg alone does not stop collapse, as we will see below). Ē can simply be E itself, or a copy of E that slowly catches up with it (at each step it moves only a little towards E; this is called an exponential moving average, EMA).

Reconstruction keeps whatever is most prominent in the picture, useful or not. Predicting only the value keeps just the essentials, but it knows only this one task: change the goal and it has to be relearned, and when rewards are sparse, the learning signal is too weak. Predicting in representation space drops what cannot be predicted, but it still keeps irrelevant things that can be predicted (the slowly drifting blobs). In real reinforcement learning the difference is plain to see: studies that replaced the backgrounds in DeepMind Control (a suite of simulated robot control tasks) with moving natural videos found that models relying on reconstruction got markedly worse, while representations that look only at "what matters for the task" were affected far less (Zhang et al. 2021; Wang et al. 2022).

再来看坍塌。下面训练一个最小的 JEPA：编码器把每帧（手指、圆盘、两团乱闪的光斑的位置）压成 2 个数，再让它从这一帧的 2 个数和动作，预测下一帧的 2 个数。Now for collapse. Below, a minimal JEPA is trained: the encoder squeezes each frame (the positions of the finger, the puck and two flickering blobs) into 2 numbers, and it must then predict the next frame’s 2 numbers from this frame’s 2 numbers and the action.

L = Lpred + α Σj max(0, 1 − std(zj))² + β Σi≠j Cov(z)ij²

在预测误差之外再加两项：每一维 z 在不同画面之间的标准差不能小于 1；不同维之间不能相关。On top of the prediction error, add two terms: the standard deviation of each dimension of z across different frames must not fall below 1, and different dimensions must not be correlated.

坍塌的样子是"所有画面的 z 都挤在一起"。第二项直接禁止挤在一起：哪一维的标准差掉到 1 以下就罚分。可光有这一条还不够，编码器可以让两维变得一模一样，等于只用了一维，第三项就禁止这种重复。这仿照的是 VICReg（Bardes、Ponce、LeCun 2022）：它原本的第一项是让同一张图的两个变形版本编码一致（"不变"），这里换成了"预测要准"；后两项基本照搬。Collapse looks like "the z of every frame crowded together". The second term forbids crowding outright: any dimension whose standard deviation drops below 1 is penalised. But that alone is not enough: the encoder could make its two dimensions identical, which amounts to using only one, and the third term forbids that kind of duplication. This copies VICReg (Bardes, Ponce and LeCun 2022): there, the first term makes two distorted versions of the same image encode alike ("invariance"); here it is replaced by "the prediction must be accurate", and the other two terms are taken over more or less as they are.

防坍塌，现在大致有四种办法：There are now roughly four ways to prevent collapse:

  • 直接管住统计量：VICReg 那样要求方差和去相关；LeJEPA（Balestriero & LeCun 2025）更进一步，要求所有 z 的分布接近一个各方向一样的高斯（SIGReg），用一个有理论保证的正则项代替各种经验技巧。Control the statistics directly: require variance and decorrelation, as VICReg does. LeJEPA (Balestriero & LeCun 2025) goes further: it requires the distribution of all the z to be close to a Gaussian that is the same in every direction (SIGReg), replacing the various empirical tricks with one regularisation term that has theoretical guarantees.
  • 不对称的结构："答案"那一侧用 EMA 副本并停止梯度，预测那一侧多一个预测器。BYOL（Grill 等 2020）发现这样就不容易坍塌，I-JEPA（2023）、V-JEPA（2024）、V-JEPA 2（2025）都这样做。它在实践中很管用，为什么管用，理论上还没有完全讲清。An asymmetric structure: the "answer" side uses an EMA copy and a stop-gradient, while the prediction side has an extra predictor. BYOL (Grill et al. 2020) found that this makes collapse unlikely, and I-JEPA (2023), V-JEPA (2024) and V-JEPA 2 (2025) all do the same. It works very well in practice, but why it works has not yet been fully explained in theory.
  • 拿任务来撑：TD-MPC2（Hansen 等 2024）的潜空间同时要预测下一步的潜状态、奖励和价值；奖励和价值让潜变量没法缩成一个点，代价是只装和这些任务有关的东西。Hold it up with the task: the latent space of TD-MPC2 (Hansen et al. 2024) must predict the next latent state, the reward and the value all at once. The reward and value stop the latent from shrinking to a point, at the price of holding only what is relevant to these tasks.
  • 拿重建来撑：Dreamer 那样，要求 z 能把画面画回来。这当然不会坍塌，可又回到了这一步开头的那个毛病。Hold it up with reconstruction: as Dreamer does, require z to be able to redraw the picture. This certainly cannot collapse, but it brings back the flaw from the start of this step.

还有一条近路：编码器干脆不自己学，直接借一个在海量图片上预训练好的视觉模型来用。DINO-WM（Zhou 等 2024）就在 DINOv2 的特征上学"下一步"，再在这个空间里规划，不需要重建，也不用担心坍塌。There is also a shortcut: skip learning the encoder altogether and borrow a vision model that has already been pretrained on huge numbers of images. DINO-WM (Zhou et al. 2024) learns "the next step" on DINOv2 features and then plans in that space, with no reconstruction needed and no collapse to worry about.

到这里，"预测什么、在哪里预测"都有了几种答案。可模型本身不会动手：学好了，到底怎样用它挑出动作？开头那个"让它自己想 160 种"，只是其中一种办法。By now there are several answers to "what to predict, and where". But a model does not act by itself: once it is learned, how exactly do you use it to choose actions? The "Let it imagine 160 pushes" at the start is only one way.

第 ⑤ 步 · 怎么用Step ⑤ · Using it

学好了，怎么用How to use a learned model

有了一个够准的世界模型，怎样把它变成动作？大致有三种办法，区别在于"想"放在什么时候：每走一步都现想；往前把各种走法搜一遍；还是事先在模型里练好，到时候不用想。With a world model that is accurate enough, how do you turn it into actions? There are roughly three ways, and they differ in when the "thinking" happens: think afresh at every step; search through the possible moves ahead; or practise in the model beforehand, so that no thinking is needed when the time comes.

第一种：边想边做（MPC）。每走一步，都在模型里往前想 H 步，找出最好的一串动作，只执行第一个，然后看清真实世界变成了什么样，再从头想。第六篇里甩起摆杆的，就是它。First: plan as you go (MPC). At every step, imagine H steps ahead in the model, find the best sequence of actions, carry out only the first one, then see what the real world actually looks like now, and think it all through again from the start. This is what swung the pendulum arm up on page 6.

at:t+H−1 = argmin Στ=1..H c(ŝt+τ), ŝt+τ = f(ŝt+τ−1, at+τ−1), ŝt = st

从现在的真实状态出发，在模型里试一串动作，把一路上的代价加起来；挑总代价最小的那一串，只执行它的第一个动作。Starting from the current real state, try a sequence of actions in the model and add up the cost along the way; pick the sequence with the smallest total cost and carry out only its first action.

每一步都从真实状态重新出发，模型的误差就没有机会累积太久（第 ① 步）；只执行第一个动作，是因为后面的动作是在"想象的未来"里定的，等真走到那一步，再根据真实情况重定。代价 c 可以随时换：换一个目标、加一个"别碰到边"，下一步就按新的来，不用重新训练。Because every step starts again from the real state, the model’s errors never get the chance to compound for long (step ①). Only the first action is carried out because the later ones were decided in an "imagined future"; when that step actually comes, they are decided again from what is really there. The cost c can be changed at any time: switch to a different goal or add "don’t hit the rim", and from the very next step it follows the new cost, with no retraining.

下棋时每走一步都重新算几步，但只落一个子。Before every move in chess, you calculate a few moves ahead all over again, but you play only one move.

"找最好的一串"通常靠随机试：交叉熵方法（CEM）先随机撒一批动作序列，留下最好的几条，在它们附近再撒一批，重复几轮；交互里用的 MPPI（Williams 等 2016）撒 64 条，每条按 exp(−总代价 ÷ λ) 加权，再把 64 串动作按权重平均成一串（λ 像"温度"：越小，越只听代价最低的那几条）。每走一步要调用模型 64 × 12 = 768 次。"Finding the best sequence" is usually done by random trial: the cross-entropy method (CEM) scatters a batch of random action sequences, keeps the best few, scatters a new batch around them, and repeats this for a few rounds. The MPPI used in the interactive (Williams et al. 2016) scatters 64 sequences, weights each by exp(−total cost ÷ λ), and averages the 64 action sequences with these weights into one (λ acts like a "temperature": the smaller it is, the more only the lowest-cost few count). Every step calls the model 64 × 12 = 768 times.

它最灵活，也最贵：每一步都要在模型里推几百上千次，对机器人的算力和速度都是负担。而且它只看得到 H 步以内：H 太短，看不见"先绕到后面再推"这种要先付出、后得回报的走法。It is the most flexible, and also the most expensive: every step means running the model hundreds or thousands of times, a burden on both the robot’s computing power and its speed. And it sees only H steps ahead: if H is too short, it cannot see moves like "first go round behind, then push", which cost something now and pay off later.

第二种：往前搜（树搜索）。动作是有限几种（下棋的每一步、或者把方向切成 8 个）时，可以把"我这样走，它会怎样，我再那样走……"展开成一棵树，挑最好的分支。MuZero 就在它学出来的潜空间里做蒙特卡洛树搜索（MCTS）：树往有希望的地方长，叶子上不用推演到底，而是让价值网络估一下"从这里往后还能拿多少分"。Second: search ahead (tree search). When there are only a few possible actions (the moves in chess, or directions cut into 8), "if I move like this, what will it do, and then if I move like that…" can be unfolded into a tree, and the best branch picked. MuZero runs Monte Carlo tree search (MCTS) in the latent space it has learned: the tree grows towards promising places, and at the leaves, instead of rolling out to the end, a value network estimates "how many more points can be won from here on".

第三种：先在想象里练好（策略）。把"想"全部挪到训练时：在模型里让一个策略网络 π 练几千几万个回合，练好了，真用的时候看一眼状态就给出动作，一步只算一次网络。Dreamer 就这样做：从真实见过的状态出发，在潜空间里想象 15 步，用想象的奖励和一个学出来的价值来训练策略。Third: practise in imagination first (a policy). Move all the "thinking" to training time: let a policy network π practise in the model for thousands or tens of thousands of episodes; once it is trained, in real use it just glances at the state and gives an action, running the network only once per step. Dreamer does exactly this: starting from states it has really seen, it imagines 15 steps ahead in the latent space and trains the policy on the imagined rewards and a learned value.

模型和策略都是可以求导的网络，所以"把参数 φ 改一点，总代价会怎么变"可以沿着整条想象的轨迹一步步往回算（反向传播穿过模型）。最早的 Dreamer 就是这样，沿着学出来的动力学把价值的梯度传回来（后来的版本，尤其是动作离散的时候，改用了不必穿过模型求导的办法）。真实世界不能求导，模型能，这是在模型里练的一大好处。The model and the policy are both differentiable networks, so "how the total cost would change if φ were nudged a little" can be worked out step by step backwards along the whole imagined trajectory (backpropagation through the model). That is how the first Dreamer trained its policy: the gradient of the value is passed back along the learned dynamics (later versions, especially with discrete actions, switched to methods that do not need to differentiate through the model). The real world cannot be differentiated, but the model can; that is one of the great advantages of practising in the model.

第 ⑥ 步 · 视频Step ⑥ · Video

放大到视频Scaling up to video

上一篇讲的扩散和 Flow Matching，2023 年以后被用来生成越来越像真的视频。给它们加上动作作为条件，就成了一类新的世界模型：看着前面几帧画面，听你说"往左"或"往前开"，画出接下来的几帧。它们多半也先把画面压缩（上一篇第 ⑩ 步），但这个压缩要求能把整张画面原样画回来，所以预测的本质上还是整个画面：世界有多复杂，它就画多复杂。几个有代表性的：Diffusion and flow matching, covered on the previous page, have been used since 2023 to generate video that looks more and more real. Give them actions as a condition and they become a new kind of world model: they look at the last few frames, hear you say "go left" or "drive forward", and draw the next few frames. Most of them also compress the picture first (step ⑩ of the previous page), but that compression must be able to redraw the whole picture exactly, so what they predict is still, in effect, the whole picture: as complex as the world itself. A few representative examples:

  • 驾驶：GAIA-1（Wayve 2023）以视频、文字和车的动作为条件，生成接下来的路况，可以拿来造"罕见但危险"的场景。Driving: GAIA-1 (Wayve 2023) is conditioned on video, text and the car’s actions, and generates what happens next on the road; it can be used to create "rare but dangerous" scenarios.

放大到视频以后，有四个问题特别突出：Once you scale up to video, four problems stand out:

  • 越推越歪。每一帧的小瑕疵，下一帧被当成真的接着画，几十帧以后画面就面目全非。最常用的对策是噪声增强：训练时故意给上下文的帧加上随机的噪声（GameNGen 就这样做；下面的交互里还加了模糊），模型就学会了"从有点脏的画面接着往下画好"。Oasis 还在生成时按一个时间表给上下文加噪声（"动态加噪"），道理相同。更彻底的办法，是训练时就让模型吃自己生成的帧（Self Forcing，Huang 等 2025），或者给每一帧各加不同程度的噪声一起训练（Diffusion Forcing，Chen 等 2024）。Drift. Small flaws in one frame are treated as real when the next frame is drawn from it, and after a few dozen frames the picture is unrecognisable. The most common fix is noise augmentation: during training, random noise is deliberately added to the context frames (GameNGen does this; the interactive below also adds blur), so the model learns to "carry on drawing well from a slightly dirty picture". Oasis also adds noise to the context on a schedule while generating ("dynamic noising"), for the same reason. A more thorough fix is to feed the model its own generated frames during training (Self Forcing, Huang et al. 2025), or to train with a different level of noise on each frame (Diffusion Forcing, Chen et al. 2024).
  • 记忆。上下文只能放下几秒钟的画面。转身看墙，再转回来，刚才的房间可能已经变了样。要在几分钟里保持前后一致，就得有更长的记忆，或者把看过的东西存下来以后再查。Memory. The context only holds a few seconds of video. Turn to face a wall, turn back, and the room you were just looking at may have changed. To stay consistent over a few minutes, a model needs a longer memory, or a way to store what it has seen and look it up later.
  • 实时。扩散模型生成一帧要走好多步，可交互的世界模型一秒要出十几到几十帧，于是少步采样和蒸馏（上一篇第 ⑩ 步）成了标配。Real time. 再说动作。没有动作标签，能不能学出一个"听动作"的世界模型？Genie 的办法是让模型自己发明动作：Now for the actions. Without action labels, can you learn a world model that "follows actions"? Genie’s approach is to let the model invent the actions itself:

ât = ψ( o≤t, ot+1 ) ∈ {1, 2, …, 8}, ôt+1 = f( o≤t, ât )

看着以前的画面和下一帧，把"这一步发生了什么变化"压成 8 选 1 的一个代码 â；再要求只凭以前的画面和这个代码，就能画出下一帧。Looking at the earlier frames and the next one, squeeze "what changed in this step" into a code â with just 8 possible values; then require that the next frame can be drawn from the earlier frames and this code alone.

代码只有 8 种，装不下"下一帧长什么样"，只能装下变化里最要紧、又没法从以前的画面猜出来的那一点。在游戏视频里，这一点恰恰就是玩家按了什么键：敌人怎么走、东西怎么往下掉，都能从以前的画面猜到；只有玩家按了什么键（以及由它带来的角色移动、画面滚动）猜不到。这和第 ③、④ 步的压缩是同一个道理：口子越窄，越只能留下最要紧、又猜不到的那点东西（这叫信息瓶颈）。With only 8 codes, there is no room for "what the next frame looks like"; there is room only for the part of the change that matters most and cannot be guessed from the earlier frames. In game videos, that part is exactly which key the player pressed: where the enemies go and how things fall can all be guessed from earlier frames; only which key the player pressed (and the movement of the character and the scrolling of the screen that follow from it) cannot. This is the same idea as the compression in steps ③ and ④: the narrower the opening, the more only the most important, least guessable part can get through (this is called an information bottleneck).

潜动作不是机器人真实的电机指令。要用到机器人上，还需要少量带真实动作的数据，把潜动作翻译成真动作：LAPA（Ye 等 2024）先在大量机器人视频上学潜动作、预训练策略（不看这些视频的动作标签），再用少量带动作的机器人数据微调，结果超过了用动作标签预训练的 OpenVLA；只用人手操作的视频来预训练，也有帮助；更早的 LAPO（Schmidt & Jiang 2023）证明了不看动作标签也能学到可用的潜动作。Latent actions are not a robot’s real motor commands. To use them on a robot, you still need a small amount of data with real actions, to translate latent actions into real ones: LAPA (Ye et al. 2024) first learns latent actions and pretrains a policy on large amounts of robot video (without using its action labels), then fine-tunes on a small amount of robot data with actions, and ends up ahead of OpenVLA, which was pretrained with action labels; pretraining on video of human hands alone also helps; the earlier LAPO (Schmidt & Jiang 2023) showed that usable latent actions can be learned without looking at action labels.

视频世界模型画得越来越像了，可"像"和"对"是两回事。下一步专门问：它到底懂不懂物理？Video world models draw more and more convincing pictures, but "looking right" and "being right" are two different things. The next step asks directly: does it really understand physics?

第 ⑦ 步 · 懂物理吗Step ⑦ · Understanding physics?

它懂物理吗Does it understand physics?

视频世界模型画出来的东西越来越像真的，于是人们常说它"学会了物理"。真是这样吗？几项专门的研究给出的答案都偏向否定：What video world models draw looks more and more real, so people often say they have "learned physics". Is that really so? Several studies that set out to test this all give answers that lean towards no:

  • Kang 等 2024 用最简单的 2D 物理（小球匀速运动、碰撞、抛物线）训练视频生成模型。在训练数据的范围内，它们几乎完美；速度、大小一超出见过的范围，就错得离谱，而且加大模型、加多数据都救不回来。它们更像是在"找最像的那段训练视频照着画"，而不是学到了规律；找"最像"的时候，看颜色比看大小重要，看大小又比看速度重要。Kang et al. 2024 trained video generation models on the simplest 2D physics (a ball moving at constant velocity, collisions, parabolic motion). Within the range of the training data they were almost perfect; as soon as the speed or size went beyond what they had seen, they were wildly wrong, and neither bigger models nor more data could rescue them. They behave more like "find the most similar training video and copy it" than like something that has learned the laws; and when finding "the most similar", colour counts for more than size, and size for more than speed.
  • Physics-IQ（Motamed 等 2025）拍了一批真实的物理现象（固体碰撞、液体、光、磁），让各家视频模型接着往下生成。结论是：画得像不像，和物理对不对，几乎没有关系。Physics-IQ (Motamed et al. 2025) filmed a set of real physical events (solids colliding, liquids, light, magnetism) and had various labs’ video models continue them. The conclusion: how realistic the pictures look has almost nothing to do with whether the physics is right.

这并不奇怪。第 ③ 步说过，训练目标只要求"下一帧和真的一样"；一个物理规律如果在数据里没有被反复检验过（比如没见过的速度、没见过的碰撞角度），模型就没有理由把它学对。"像"是在数据里平均意义下的像；"对"却要求在每一个具体情况下都对，包括少见的情况。This is not surprising. As step ③ said, the training objective only asks for "the next frame to match the real one"; if a physical law has not been tested again and again in the data (for example at speeds or collision angles never seen), the model has no reason to learn it correctly. "Looking right" means looking right on average over the data; "being right" means being right in every single case, including the rare ones.

所以考一个世界模型，光看它画得好不好远远不够。至少要问五件事：So to test a world model, looking at how well it draws is far from enough. You need to ask at least five things:

  • 像不像：画面和真实视频的统计差别（比如 FVD 这类分数：把真假两堆视频用同一个预训练网络编码，比较编码的分布差多远）。必要，但只是起点。Does it look real? The statistical difference between its frames and real video (scores such as FVD: encode the real and the generated videos with the same pretrained network, and compare how far apart the two distributions of codes are). Necessary, but only a starting point.
  • 听不听动作：同一个开头，换不同的动作，未来跟着变吗？变得对吗？这叫反事实测试：真实世界里，同一时刻只能做一种动作，模型却要回答"如果当时那样做呢"。Does it follow the actions? From the same start, with different actions, does the future change with them? Does it change in the right way? This is called a counterfactual test: in the real world only one action can be taken at a given moment, but the model has to answer "what if I had done it that way instead?"
  • 守不守规矩：东西会不会穿过彼此、凭空消失或出现？该停的停住了吗？Does it obey the rules? Do objects pass through each other, or vanish or appear out of nowhere? Do things that should stop actually stop?
  • 没见过的情况：撞墙、翻倒、极快极慢，这些在数据里少见的事，它怎么画？Unseen situations: how does it draw things that are rare in the data, such as hitting a wall, tipping over, or moving very fast or very slowly?
  • 用起来行不行：拿它来规划、来评测策略，结果和真实世界对得上吗？第 ⑧ 步会看一个例子。Does it work in practice? When you use it to plan or to evaluate policies, do the results match the real world? Step ⑧ looks at an example.

The "Never saw the rim" model is accurate on familiar ground, but as soon as it reaches the edge it sends objects off the table: "I don’t know" is not an option it has. A model is always weakest where it has the least data.

评测世界模型，因此慢慢从"看画面"转向"看用处"：除了 Physics-IQ 这类物理测试，WorldModelBench（2025）同时检查是否听指令、是否违反常识物理；还有越来越多的工作直接把世界模型放进闭环里，看拿它规划或评测出来的结果，在真实世界里站不站得住。机器人恰恰最需要后者。So the evaluation of world models is slowly shifting from "looking at the pictures" to "looking at what they are good for": besides physics tests such as Physics-IQ, WorldModelBench (2025) checks both whether a model follows instructions and whether it breaks common-sense physics; and more and more work puts the world model straight into a closed loop, to see whether the plans or evaluations made with it hold up in the real world. That last kind is exactly what robots need most.

第 ⑧ 步 · 机器人Step ⑧ · Robots

机器人里怎么用How robots use it

机器人是世界模型最自然的用户：真机试错又慢、又贵、又危险，能在脑子里先试，好处最大。到 2026 年，世界模型在机器人里大致有五种用法，从"帮忙"到"直接当家"：Robots are the most natural users of world models: trial and error on a real robot is slow, expensive and dangerous, so being able to try things in your head first pays off most. As of 2026, robots use world models in roughly five ways, ranging from "helping out" to "taking charge":

  • 规划：在模型里想好再动。这是第 0 步、第 ⑤ 步的做法搬到真机上。V-JEPA 2（Meta 2025）先在一百多万小时的网络视频上学表示，再只用不到 62 小时的机器人视频（带着机械臂自己记下的动作，但没有任务标注，也没有奖励），学会"这样动手，画面的编码会怎么变"；给它一张目标图片，它在表示空间里用 CEM 搜出动作，在两个从没去过的实验室里，零样本（没在那里收过数据，也没再训练）完成了抓取和放置。DINO-WM 在预训练的视觉特征上做同样的事；Navigation World Models（Bar 等 2024）想象沿各条路线走会看到什么，挑出能到终点的那条。Planning: think it through in the model, then act. This is the approach of step 0 and step ⑤, moved onto real robots. V-JEPA 2 (Meta 2025) first learns representations from over a million hours of internet video, then, from less than 62 hours of robot video (with the actions the arm itself recorded, but no task labels and no rewards), learns "if I move like this, how will the encoding of the picture change"; given a goal image, it searches for actions with CEM in representation space, and in two labs it had never been to, it carried out pick-and-place zero-shot (with no data collected there and no retraining). DINO-WM does the same on pretrained visual features; Navigation World Models (Bar et al. 2024) imagines what it would see along each route and picks the one that reaches the destination.
  • 在想象里练：DayDreamer（Wu 等 2022）把 Dreamer 直接放到四台真机器人上，不用仿真器；一台四足机器人从零开始，大约一个小时就学会了从仰面躺着翻过来、站起来、走路。近两年，人们开始在学出来的视频世界模型里，用强化学习微调大的 VLA 策略（视觉–语言–动作模型：看画面、听指令、直接输出动作的大模型）：WMPO（2025）整个强化学习过程都在想象的画面里进行，不碰真机。Practising in imagination: DayDreamer (Wu et al. 2022) put Dreamer straight onto four real robots, with no simulator; a quadruped robot starting from scratch learned in about an hour to roll over from lying on its back, stand up and walk. In the past two years, people have started fine-tuning large VLA policies (vision–language–action models: large models that look at images, listen to instructions and output actions directly) with reinforcement learning inside learned video world models: WMPO (2025) runs the entire reinforcement learning process in imagined frames, without touching a real robot.
  • 评测策略：每出一版新策略，都在真机上跑几百次来打分，太慢了。于是用世界模型当考场：1X 的世界模型从同样的开局出发，预测人形机器人的不同策略会怎么做、能不能成功；Google DeepMind 用 Veo 视频模型搭了一个模拟器来测 Gemini Robotics 的策略，包括没见过的场景和安全测试（2025）；WorldGym、WorldEval 都报告说，模型里给策略排的名次和真机上的对得上；Ctrl-World 评测完，还在想象的画面里接着改进策略。下面的交互就看评测这件事。Evaluating policies: scoring every new version of a policy by running it hundreds of times on a real robot is far too slow. So a world model serves as the exam hall: 1X’s world model predicts, from the same starting positions, what different policies for a humanoid robot will do and whether they will succeed; Google DeepMind built a simulator on its Veo video model to test Gemini Robotics policies, including unseen scenes and safety tests (2025); WorldGym and WorldEval both report that the ranking of policies in the model matches the ranking on real robots; Ctrl-World, after evaluating, goes on to improve the policy in imagined frames. The interactive below looks at evaluation.
  • 造数据：DreamGen（NVIDIA 2025）把视频世界模型调到某一台机器人上，让它"想象"这台机器人做各种新任务的视频，再用一个反推动作的模型（或潜动作模型）给这些视频补上动作，拿这些"想象出来的轨迹"训练策略；一台人形机器人就这样学会了 22 种新动作。NVIDIA 的 Cosmos 也常被用来生成训练数据。Making data: DreamGen (NVIDIA 2025) fine-tunes a video world model on one particular robot, has it "imagine" videos of that robot doing all sorts of new tasks, then uses a model that recovers actions from video (or a latent action model) to add actions to these videos, and trains a policy on these "imagined trajectories"; that is how a humanoid robot learned 22 new behaviours. NVIDIA’s Cosmos is also often used to generate training data.
  • 直接当策略：先想象出"任务完成的视频"，再从视频里读出动作。UniPi（Du 等 2023）按一句指令生成一段视频，再用一个反推动作的模型把视频变成控制指令；GR-2（2024）先在 3800 万段网络视频上学"预测下一帧"，再同时生成视频和动作；UVA（2025）让视频和动作共用一个潜空间，运行时可以跳过画视频直接出动作。2026 年，这条路有了个名字，"世界动作模型"：NVIDIA 的 DreamZero 一起预测未来的画面和动作，零样本做新任务，还能换到别的机器人身上；1X 也把它的世界模型直接变成了人形机器人 NEO 的策略（2026）。Acting as the policy: first imagine "a video of the task being done", then read the actions off the video. UniPi (Du et al. 2023) generates a video from a one-sentence instruction, then uses a model that recovers actions to turn the video into control commands; GR-2 (2024) first learns to "predict the next frame" on 38 million internet video clips, then generates video and actions together; UVA (2025) lets video and actions share one latent space, so at run time it can skip drawing the video and output actions directly. In 2026 this route got a name, "world action model": NVIDIA’s DreamZero predicts future frames and actions together, does new tasks zero-shot and can even be moved to other robots; 1X has also turned its world model directly into the policy of its humanoid robot NEO (2026).

评测这件事最能说明世界模型的价值和风险。在真机上比较几个策略，要每个跑几十上百次；在模型里比，不用碰真机，可以很多局一起跑，又快又便宜（这张小桌子上几秒钟就有结果）。可模型里的成绩只有在排名和真实世界对得上时才有用：绝对的成功率偏一点没关系，只要好的仍然排在前面，挑出来的就还是对的。Evaluation shows both the value and the risk of world models better than anything else. Comparing a few policies on a real robot means running each one dozens or hundreds of times; comparing them in a model needs no real robot, can run many episodes at once, and is fast and cheap (on this small table it takes a few seconds). But scores in the model are only useful if the ranking matches the real world: it does not matter if the absolute success rates are a little off, as long as the good policies still come out on top, because then the one you pick is still the right one.

这五种用法，现在都还和传统的仿真器并存。刚体、关节这些写得清楚的物理，人写的仿真器又快又准，第六篇讲的仿真里练强化学习至今是腿足机器人的主力；学出来的世界模型，用在仿真器写不清的地方：软的、碎的、液体，真实相机拍到的样子，以及需要"见过很多东西"才能判断的开放场景。All five of these uses still exist alongside traditional simulators. For physics that can be written down clearly, such as rigid bodies and joints, hand-written simulators are fast and accurate, and reinforcement learning in simulation, covered on page 6, is still the mainstay for legged robots. Learned world models are used where simulators cannot spell things out: soft things, crumbly things and liquids, what a real camera sees, and open-ended scenes that take "having seen a lot of things" to judge.

第 ⑨ 步 · 光谱Step ⑨ · The spectrum

几十种世界模型，放在一起看Dozens of world models, side by side

到这里已经见过几十种世界模型。它们看上去各有一套，其实都在回答开头那个问题：做了这个动作，接下来会怎样。差别在于几个选择：By now we have met dozens of world models. Each seems to have its own system, but they are all answering the question we started with: given this action, what happens next? The differences come down to a few choices:

  • 在哪个空间里预测。几个有物理意义的数（状态）；一小串要能画回画面的数（靠重建学的潜变量）；只为任务服务的潜状态；表示空间里的编码；还是画面本身。要求装得越全（比如要能画回画面），越难预测准；有物理意义的状态是个特例：又小又全，可惜往往读不到。Where it predicts. A few physically meaningful numbers (the state); a short string of numbers that must be able to redraw the picture (a latent learned by reconstruction); a latent state that serves only the task; an encoding in representation space; or the picture itself. The more completely it is required to hold everything (for example, enough to redraw the picture), the harder it is to predict accurately; the physically meaningful state is a special case: small and complete, but often impossible to read.
  • 怎么训练。回归或最大似然（直接预测下一步）；重建加 KL（上一篇的证据下界）；只预测奖励、价值和动作；在表示空间里预测、再想办法防坍塌；用扩散或自回归生成画面。How it is trained. Regression or maximum likelihood (predicting the next step directly); reconstruction plus KL (the evidence lower bound from the previous page); predicting only reward, value and action; predicting in representation space while finding some way to prevent collapse; or generating the picture with diffusion or autoregression.
  • 动作从哪来。训练数据带着动作标签；从没有标签的视频里自己发明潜动作；用一句话或别的条件代替；或者根本不看动作。Where the actions come from. The training data comes with action labels; the model invents latent actions of its own from unlabelled video; a sentence or some other condition stands in for the actions; or the model ignores actions altogether.
  • 拿来干什么。规划、树搜索、在想象里练策略、评测策略、造数据、直接当策略、当一个人能进去玩的模拟器，或者只借"预测"来学一个好的表示。What it is used for. Planning, tree search, practising a policy in imagination, evaluating policies, making data, acting directly as the policy, serving as a simulator that people can step into and play, or just borrowing "prediction" to learn a good representation.

把这张图换着几种分法看一遍，能看出几条线索：Going through the map under several groupings, a few threads emerge:

  • 预测的空间往两头走。早期在状态里预测，后来为了处理画面，先压缩再预测。之后分成了两个方向：一头越来越"抽象"，只装和任务有关的（MuZero、TD-MPC2），或者只装能预测的（JEPA）；另一头越来越"具体"，直接生成整个画面（视频世界模型）。前者算得快、不容易被背景干扰；后者人看得懂、能直接拿来造数据。两头都在吃海量视频（V-JEPA 2 预训练用了一百多万小时），至今并存。The prediction space has moved towards both ends. Early models predicted in the state; later, to handle pictures, they compressed first and then predicted. After that, things split two ways: at one end, models have become ever more "abstract", holding only what matters for the task (MuZero, TD-MPC2), or only what can be predicted (JEPA); at the other, ever more "concrete", generating the whole picture directly (video world models). The former are fast to compute and not easily distracted by the background; the latter are easy for people to understand and can be used directly to make data. Both ends feed on vast amounts of video (V-JEPA 2 was pretrained on over a million hours), and both still exist side by side today.
  • 用法越来越多。早期的世界模型都是为了自己规划或练策略；2023 年起，它们开始被拿来给别的策略造数据（GAIA-1、UniSim），或者干脆自己当策略（UniPi、GR-2）；2024 年起，又多了评测别人的策略这一种用法；2026 年，"世界动作模型"把想象未来和出动作合进了同一个模型。The uses keep multiplying. Early world models were all built to plan or practise a policy for themselves; from 2023, they began to be used to make data for other policies (GAIA-1, UniSim), or to act as the policy themselves (UniPi, GR-2); from 2024, another use was added, evaluating other people’s policies; and in 2026, "world action models" merged imagining the future and producing actions into a single model.
  • 动作越来越不需要标签。从必须有动作标签，到从视频里发明潜动作、用文字当条件，世界模型越来越能吃网上的视频。Action labels are needed less and less. From needing action labels, world models have moved on to inventing latent actions from video and using text as the condition, and they are more and more able to feed on internet video.
  • 生成部分和上一篇合流了。视频世界模型大多用扩散或 Flow Matching 来画画面（也有把画面切成词元、一个个往下生成的），上一篇里的少步采样、蒸馏、引导，在这里全都用得上。The generative part has converged with the previous page. Most video world models draw their frames with diffusion or flow matching (some instead cut the picture into tokens and generate them one by one), and the few-step sampling, distillation and guidance from the previous page all apply here.

总结Summary

回到开头：能不能先在脑子里试一试Back to the start: can you try it in your head first?

能，而且已经在这样做了。机器人先在学出来的模型里试各种做法，挑出好的再动手；或者在模型里先练好策略；或者拿模型来考自己的策略、给自己造数据。但"在脑子里试"有用的前提是：脑子里的世界和真实的世界，在机器人要去的地方足够像。整篇讲的，就是怎样让它足够像，以及不够像的时候怎样不被它骗：想一步走一步，用真实状态不断纠偏（①）；知道自己哪里没把握，别让规划器去钻那些地方（②）；对说不准的未来抽签，而不是取平均（③）；只装该装的东西，又不让它坍塌（④）；按用途选择用法（⑤）；训练时就让它习惯自己的错（⑥）；最后，用真正要用的方式去考它（⑦、⑧）。Yes, and it is already being done. Robots try out different ways of acting in a learned model first, pick the good ones and only then act; or they train a policy in the model first; or they use the model to test their own policies and to make data for themselves. But "trying it in your head" is only useful on one condition: in the places the robot is going, the world in its head must be close enough to the real world. This whole page has been about how to make it close enough, and how not to be fooled by it when it isn’t: think a step, take a step, and keep correcting course with the real state (①); know where it is unsure, and don’t let the planner exploit those places (②); when the future is uncertain, draw a sample instead of taking the average (③); hold only what it should hold, without letting it collapse (④); choose how to use it according to what it is for (⑤); get it used to its own errors while it is still training (⑥); and finally, test it the way it will really be used (⑦, ⑧).

其他几个问题Other questions

  • 世界模型是什么？一个从数据里学出来的"如果……会怎样"：给它现在的样子和一个动作，它告诉你接下来的样子。仿真器的规则是人写的，它的规则是学的；视频生成可以不管动作，它必须听动作；控制里 MPC 用的那个模型，学出来的就是它（第 0 步）。What is a world model? A "what if…" learned from data: give it how things are now and an action, and it tells you how things will be next. A simulator’s rules are written by people, while a world model’s rules are learned; video generation can ignore actions, but a world model must follow them; and the model that MPC uses in control, once it is learned from data, is exactly a world model (step 0).
  • 预测什么、在哪个空间里预测？见上表。空间越小越好预测，但可能丢掉要紧的东西；要求装得越全（比如要能画回画面），越难预测准，也越容易被无关的东西占满（③、④）。What does it predict, and in which space? See the table above. The smaller the space, the easier it is to predict in, but it may lose things that matter; the more completely it is required to hold everything (for example, enough to redraw the picture), the harder it is to predict accurately, and the more easily it fills up with irrelevant things (③, ④).
  • 学好了拿来干什么？边想边做（MPC）、往前搜（树搜索）、先在想象里练好（策略）；到了机器人上，还多了评测策略、造数据、直接当策略（⑤、⑧）。Once learned, what is it used for? Plan as you go (MPC), search ahead (tree search), practise in imagination first (a policy); on robots, it is also used to evaluate policies, to make data and to act directly as the policy (⑤, ⑧).
  • 它有哪些毛病？推远了误差会累积（①）；没见过的地方会乱说，规划器偏偏专门往那儿钻（②）；未来不止一种时，均方误差给出一个糊的平均（③）；为了重建，要记住无关的细节（④）；在表示空间里预测会坍塌（④）；视频越推越歪（⑥）；看起来对不等于真的对：不听动作、没见过的情况，都会露馅（⑦）。What are its weaknesses? Errors compound over long rollouts (①); it talks nonsense where it has seen no data, and the planner makes a point of exploiting exactly those places (②); when there is more than one possible future, mean squared error gives a blurry average (③); reconstruction makes it remember irrelevant details (④); prediction in representation space can collapse (④); video drifts further and further off (⑥); looking right is not being right: it gives itself away by ignoring actions and in situations it has never seen (⑦).
  • 人们怎么对付？想一步走一步，用真实状态纠偏；用集成量出不确定，悲观一点，或者只推几步；用潜变量抽样而不是取平均，再加上记忆；只装和任务有关的、或者能预测的东西，再加上防坍塌的正则；训练时加噪声，或者干脆吃自己的预测；用反事实和闭环的结果来考它。How do people deal with them? Think a step, take a step, and correct course with the real state; measure the uncertainty with an ensemble, then be a little pessimistic or roll out only a few steps; draw samples with a latent variable rather than take the average, and add memory; hold only what is relevant to the task or what can be predicted, and add a regulariser against collapse; add noise during training, or simply feed the model its own predictions; and test it with counterfactuals and closed-loop results.
  • 它懂物理吗？在数据覆盖的地方，它学到的规律常常足够用；离开数据，它更像是"找最像的见过的情况照着画"。所以画得像不能当作懂物理的证据，要专门去考：换动作、撞墙、没见过的速度，以及最终拿它做的事成不成（⑦）。Does it understand physics? In the regions the data covers, the rules it learns are often good enough; away from the data, it behaves more like "find the most similar case it has seen and draw from that". So pictures that look right cannot be taken as evidence that it understands physics; it has to be tested on purpose: change the actions, hit the wall, use speeds it has never seen, and in the end check whether the job you use it for actually works (⑦).

小测验Quiz

一个模型一步只错 2 mm，为什么往前想 50 步会错十几厘米？A model is off by only 2 mm per step. Why is it off by more than 10 cm when it imagines 50 steps ahead?

开环推演时，每一步都把上一步的预测当成真的接着算，误差会被带进下一步；输入带着误差，新犯的错也会变大；在手指碰到圆盘这种"差一点、结果差很多"的地方，误差还会被放大。所以偏差比"每步 2 mm × 50 = 10 cm"还大。办法是每一步都用真实状态重新出发（MPC），或者训练时就让模型吃自己的预测（第 ① 步）。In an open-loop rollout, each step takes the previous step’s prediction as true and continues from it, so errors are carried into the next step; with errors in its input, the new errors grow as well; and at moments like the finger touching the puck, where "a little off means a very different outcome", errors are also amplified. So the deviation ends up even larger than "2 mm per step × 50 = 10 cm". The fix is to restart from the real state at every step (MPC), or to feed the model its own predictions during training (step ①).

规划器为什么偏偏会挑中模型出错的地方？Why does the planner pick out exactly the places where the model is wrong?

规划器在模型里挑"想象中效果最好"的动作。数据之外，模型给出的数是随便猜的，其中总有一些猜得特别乐观，规划器正好会挑中它们。几个模型的分歧能指出这些地方，悲观的规划会主动避开（第 ② 步）。The planner searches the model for the action that "works best in imagination". Outside the data, the numbers the model gives are arbitrary guesses, and some of them always come out unusually optimistic; those are exactly the ones the planner picks. Disagreement among several models can point out these places, and pessimistic planning deliberately avoids them (step ②).

看不出桌面有多滑时，按均方误差训练的画面预测为什么发糊？抽一个样本的平均误差，为什么正好是它的两倍？When you can’t tell how slippery the table is, why does a prediction of the picture trained with mean squared error come out blurry? And why is the average error of a single drawn sample exactly twice as large?

均方误差最小的预测，就是所有可能未来的平均，叠在一起就糊了。随便抽两个互不相干的可能未来 X、X′，它们之间"差的平方"的平均，等于每个未来"离平均的差的平方"的平均的两倍：E‖X − X′‖² = 2 E‖X − E[X]‖²。抽出来的样本和真实的未来，正是这样两个互不相干的未来。所以只看像素误差，糊的永远赢（第 ③ 步）。The prediction with the least mean squared error is the average of all possible futures, and laid on top of one another they blur. Take two possible futures X and X′ that have nothing to do with each other: the average of their "squared difference" is twice the average "squared difference from the average" of each future: E‖X − X′‖² = 2 E‖X − E[X]‖². A sample and the real future are exactly two such independent futures. So if you look only at pixel error, the blurry one always wins (step ③).

机器人推圆盘时，背景里有一台开着的电视。靠重建学的潜变量、预测下一步的潜变量、只预测价值的潜变量，各会怎样对待电视？While the robot is pushing the puck, a TV is on in the background. How will a latent learned by reconstruction, a latent that predicts the next step and a latent that predicts only the value each treat the TV?

靠重建的：电视占的像素多、变化大，很可能挤占潜变量，连圆盘都装不下。预测下一步的：要看电视在放什么。满屏雪花没法预测，多半不装；正常的节目一帧和下一帧很像，是能预测的，它照样可能被装进去（就像慢慢飘的光斑）。只预测价值的：电视和推圆盘的奖励无关，不装（第 ④ 步）。Learned by reconstruction: the TV covers many pixels and changes a lot, so it may well take over the latent, leaving no room even for the puck. Predicting the next step: it depends on what the TV is showing. Snow all over the screen cannot be predicted, so it will most likely be left out; an ordinary programme, where each frame looks much like the last, can be predicted, so it may well be kept anyway (just like the slowly drifting blobs). Predicting only the value: the TV has nothing to do with the reward for pushing the puck, so it leaves it out (step ④).

在表示空间里预测，为什么预测误差最小的模型可能最没用？When predicting in representation space, why might the model with the smallest prediction error be the least useful?

编码器只要把所有画面都编成同一个点，预测器每次都"猜对"，误差就是 0，可这个表示什么都没记住，这就是坍塌。要加上方差、去相关这类约束，或者用 EMA 副本加预测器、用奖励和价值撑住，才能防止它（第 ④ 步）。All the encoder has to do is map every frame to the same point: the predictor then "guesses right" every time and the error is 0, yet the representation has remembered nothing. That is collapse. Preventing it takes constraints such as variance and decorrelation, or an EMA copy plus a predictor, or propping it up with reward and value (step ④).

只用网上的视频、不用动作标签训练出来的模型，能直接拿来给机器人规划吗？Can a model trained only on internet video, with no action labels, be used directly to plan for a robot?

不能直接用：它想象的未来和你做什么无关，规划器没法比较不同的动作。要么让它学潜动作，再用少量带标签的数据翻译成真动作（Genie、LAPA），要么用带动作的数据再训练（第 ⑥、⑦ 步）。Not directly: the future it imagines has nothing to do with what you do, so the planner has no way to compare different actions. Either have it learn latent actions and then translate them into real actions with a small amount of labelled data (Genie, LAPA), or train it again on data with actions (steps ⑥ and ⑦).

用世界模型来评测策略，最要紧的是什么？When a world model is used to evaluate policies, what matters most?

排名要和真实世界对得上。绝对的成功率偏一些没关系，只要好的仍然排在前面，挑出来的就是对的。还要注意：在某个模型里练出来的策略，在这个模型里的成绩会偏高，评测最好换一个模型（第 ⑧ 步）。The ranking has to match the real world. It does not matter if the absolute success rates are somewhat off: as long as the good policies still come out on top, the one you pick is the right one. Also note that a policy trained inside a model scores higher than it should in that same model, so it is best to evaluate with a different model (step ⑧).

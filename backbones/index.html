深度学习 · 网络结构 · 主干Deep learning · Network architecture · Backbones

从全连接到注意力From Fully Connected to Attention

CNN、RNN、U-Net、Transformer……神经网络的名字很多，看起来各不相同，其实都在做同一件事：一层一层地把数字混在一起，再"弯一下"。不同结构的区别只有两点：每一层让哪些位置互相混合，混合用的权重在不同位置共不共享。这两点，就是你对数据的假设。这一篇从最朴素的全连接网络讲起，一种结构一种结构地看：它长什么样，为什么要长这样，好在哪、坑在哪；然后讲清楚扩散模型为什么不是一种结构，最后看真实系统怎么把这些积木拼起来。CNN, RNN, U-Net, Transformer… neural networks come with many names and look very different, but they all do the same thing: layer by layer, they mix numbers together and then “bend” them. Architectures differ in only two ways: which positions each layer lets mix with each other, and whether the mixing weights are shared across positions. Those two choices are your assumptions about the data. This page starts from the plainest fully connected network and goes through the architectures one at a time: what each looks like, why it looks that way, what it is good at and where it breaks. Then it explains why a diffusion model is not an architecture at all, and finally looks at how real systems put these building blocks together.

第 0 步 · 总览Step 0 · Overview

所有网络都在做同一件事Every network does the same thing

上一篇说过，学习就是"一个带很多旋钮的程序，加一个打分规则，让计算机自己去拧旋钮"。这一篇只讲第一样：这个带旋钮的程序长什么样。The previous page said that learning is “a program with lots of knobs, plus a scoring rule, and the computer turns the knobs by itself”. This page is only about the first part: what the program with knobs looks like.

神经网络的输入是一串数：一张照片是几十万个像素值，机械臂此刻的状态是几十个关节角和速度。输出也是一串数："这是杯子"的概率、下一步每个关节转多少。中间的每一层只做两件事：A neural network’s input is a string of numbers: a photo is hundreds of thousands of pixel values, and a robot arm’s current state is a few dozen joint angles and velocities. The output is a string of numbers too: the probability that “this is a cup”, or how far each joint should turn next. Every layer in between does just two things:

  1. 混合：每个输出都是一些输入的加权和，权重就是那些可以学的旋钮。Mix: every output is a weighted sum of some inputs, and the weights are the learnable knobs.
  2. 弯一下：把加权和过一个简单的非线性函数，比如"负数变成 0"。为什么非弯不可，第 1 步会讲。Bend: pass the weighted sum through a simple nonlinear function, such as “negative numbers become 0”. Why the bend is essential is explained in step 1.

一层一层叠起来，就是一个神经网络。既然每一层都是"混合 + 弯一下"，不同结构差在哪？只差在混合的方式：每个输出和哪些输入相连，不同位置用不用同一组权重。这个选择就是你对数据的假设，专业的说法叫归纳偏置（inductive bias），也常叫先验。假设对了，网络就能用更少的参数、更少的数据学会；假设错了，它就学不好，或者要多得多的数据才能学会。Stack layers on top of each other and you have a neural network. If every layer is “mix + bend”, how do architectures differ? Only in how they mix: which inputs each output connects to, and whether different positions use the same set of weights. That choice is your assumption about the data, technically called an inductive bias, often also called a prior. If the assumption is right, the network learns with fewer parameters and less data; if it is wrong, the network learns badly, or needs far more data to learn.

第 1 步 · 一层是什么Step 1 · One layer

加权求和，再"弯一下"Weighted sums, then a “bend”

先看最小的单位：一个神经元。它收到几个数，给每个数乘一个权重，加起来，再加一个偏置；然后过一个非线性函数。现在最常用的是 ReLU：负数变成 0，正数原样保留。很多个神经元并排，每个都对同一组输入算一遍，就是一层；每个输入都连到这一层的每个神经元，所以叫全连接层。全连接层一层层叠起来，就是多层感知机（MLP）。Start with the smallest unit: a neuron. It receives a few numbers, multiplies each by a weight, adds them up, adds a bias, and passes the result through a nonlinear function. The most common one today is ReLU: negative numbers become 0, positive numbers pass unchanged. Many neurons side by side, each working on the same inputs, make a layer; since every input connects to every neuron in the layer, it is called a fully connected layer. Stack fully connected layers and you get a multilayer perceptron (MLP).

h = ReLU( W x + b )y = v1 h1 + v2 h2 + … + vK hK + c

隐藏层：输入 x 先乘权重矩阵 W、再加偏置 b，得到 K 个加权和，每个神经元一个；再逐个过 ReLU，负的变成 0。输出 y：把这 K 个结果 h1 到 hK 各乘一个权重 v，加起来，再加偏置 c。Hidden layer: multiply the input x by the weight matrix W and add the bias b, giving K weighted sums, one per neuron; then pass each through ReLU, so negative ones become 0. Output y: multiply each of the K results h1 to hK by a weight v, add them up, and add a bias c.

加权求和是最简单、最好算、也最容易求导的混合方式。可如果只做加权求和，叠多少层都等于一层：两个矩阵连着乘，结果还是一个矩阵，画出来只能是一条直线（在高维里是一个平面）。ReLU 是最简单的"弯一下"：每个神经元在某个地方折一下，折点多了，就能拼出任意形状。A weighted sum is the simplest way to mix, the cheapest to compute and the easiest to differentiate. But with weighted sums alone, any number of layers equals one layer: two matrices multiplied in a row are still one matrix, which can only draw a straight line (a flat plane in higher dimensions). ReLU is the simplest possible “bend”: each neuron makes one kink somewhere, and with enough kinks you can piece together any shape.

每个神经元就是一条"折线"：折点左边是 0，右边是一条斜线。输出层把这些折线按不同的比例叠起来，就能拼出各种形状。神经元越多，折点越多，能拼的形状越复杂。Each neuron is a “bent line”: 0 to the left of its kink, a sloped line to the right. The output layer stacks these bent lines in different proportions, which can piece together all sorts of shapes. More neurons mean more kinks and more complicated shapes.

两个输入 x = (1, 2)，两个神经元，W 的两行是 (1, −1) 和 (0.5, 0.5)，b = (0, −1)。加权和：1 × 1 + (−1) × 2 + 0 = −1，0.5 × 1 + 0.5 × 2 − 1 = 0.5。过 ReLU：(0, 0.5)。输出层 v = (2, 3)，c = 0.1：y = 2 × 0 + 3 × 0.5 + 0.1 = 1.6。第一个神经元的加权和是负的，被 ReLU 关掉了，对输出没有贡献。Two inputs x = (1, 2), two neurons, with W’s rows (1, −1) and (0.5, 0.5), and b = (0, −1). Weighted sums: 1 × 1 + (−1) × 2 + 0 = −1 and 0.5 × 1 + 0.5 × 2 − 1 = 0.5. After ReLU: (0, 0.5). Output layer v = (2, 3), c = 0.1: y = 2 × 0 + 3 × 0.5 + 0.1 = 1.6. The first neuron’s weighted sum is negative, so ReLU switches it off and it contributes nothing to the output.

每个旋钮该往哪拧：反向传播Which way to turn each knob: backpropagation

上面的交互里，程序直接解出了最好的输出层权重。真实的网络有几百万到几千亿个权重，一层套一层，没法直接解，只能用上一篇讲过的梯度下降：看每个旋钮往哪边拧损失会变小，就往那边拧一点，反复很多次。损失是一个衡量"输出错了多少"的数，比如 (输出 − 正确答案)²。一个权重的梯度，就是"这个权重变一点点，损失跟着变多少倍"：正负号告诉它该往哪边拧，大小告诉它影响有多大。In the interactive above, the program solved directly for the best output-layer weights. Real networks have millions to hundreds of billions of weights nested layer inside layer, so there is no direct solution; the only way is the gradient descent from the previous page: see which way turning each knob makes the loss smaller, turn it a little that way, and repeat many times. The loss is a number measuring how wrong the output is, for example (output − correct answer)². A weight’s gradient is “if this weight changes a tiny bit, by how many times that change does the loss change”: its sign says which way to turn, and its size says how much the weight matters.

问题是梯度怎么算。最笨的办法是一个一个试：把一个权重拧一点点，从头算一遍损失，看变了多少。一个有 1 亿个权重的网络，拧一步之前就要把整个网络算 1 亿遍。反向传播（backpropagation）从输出往回扫一遍，就把所有权重的梯度都算出来了，往回这一遍的计算量大约只是前向的两倍（Rumelhart、Hinton、Williams 1986）。它靠的是微积分里的链式法则：The question is how to compute the gradients. The clumsiest way is to try one at a time: nudge one weight, recompute the loss from scratch, and see how much it changed. A network with 100 million weights would have to be run 100 million times before taking a single step. Backpropagation sweeps backwards once from the output and gets the gradients of all the weights, and that backward sweep costs only about twice as much as the forward pass (Rumelhart, Hinton, Williams 1986). It relies on the chain rule from calculus:

∂ℓ/∂hl = ∂ℓ/∂hl+1 · ∂hl+1/∂hl∂ℓ/∂wl = ∂ℓ/∂hl · ∂hl/∂wl

第一行：损失对第 l 层输出的梯度，等于损失对后一层输出的梯度，乘上"后一层对这一层的局部斜率"。第二行：损失对第 l 层权重的梯度，等于损失对这一层输出的梯度，乘上"这一层的输出对它自己权重的局部斜率"。First line: the loss’s gradient with respect to layer l’s output equals the loss’s gradient with respect to the next layer’s output, times “the next layer’s local slope with respect to this layer”. Second line: the loss’s gradient with respect to layer l’s weight equals the loss’s gradient with respect to this layer’s output, times “the local slope of this layer’s output with respect to its own weight”.

一串函数套在一起：hl 变一点点，hl+1 就跟着变"局部斜率"倍；再往后每过一层，又各放大或缩小一次。所以总的倍数，就是一路上所有局部斜率的乘积，这就是链式法则。从后往前算，是因为"损失对后一层的梯度"可以被前面所有层共用：第 l + 1 层的算好了，第 l 层只要再乘一次。要是从前往后，每个权重都得单独把整条链乘一遍，又回到了一个一个试的老路。A chain of functions nested inside each other: when hl changes a tiny bit, hl+1 changes by “local slope” times as much; every later layer then scales the change up or down once more. So the total factor is the product of all the local slopes along the way: that is the chain rule. Working from back to front pays off because “the loss’s gradient with respect to the next layer” can be shared by every earlier layer: once layer l + 1 is done, layer l takes just one more multiplication. Going from front to back, every weight would need the whole chain multiplied out separately, which is back to trying one at a time.

全连接为什么不够用Why fully connected is not enough

既然一个隐藏层就能逼近任意函数，为什么还要别的结构？因为"能表示"和"学得会"是两回事。全连接层有两个毛病：If a single hidden layer can approximate any function, why bother with other architectures? Because being able to represent something and being able to learn it are two different things. Fully connected layers have two problems:

  • 参数太多。一张 224 × 224 的彩色照片有 224 × 224 × 3 = 150528 个数，只接到 1000 个神经元，就要 1.5 亿个权重。参数越多，要的数据越多，越容易死记硬背训练集。Too many parameters. A 224 × 224 colour photo has 224 × 224 × 3 = 150528 numbers; connecting them to just 1000 neurons takes 150 million weights. The more parameters, the more data you need, and the more easily the network memorizes the training set.
  • 它不知道数据的结构。对全连接层来说，输入只是一串没有顺序的数：哪两个像素相邻，它不知道；杯子在图里往右挪 10 个像素，它看到的就是一串完全不同的数，得从头再学一遍"杯子长什么样"。把所有像素按同一个固定规则打乱以后再训练，它学得一样好，这说明它根本没用上"相邻"这个信息。It does not know the structure of the data. To a fully connected layer the input is just an unordered string of numbers: it does not know which pixels are neighbours, and if the cup moves 10 pixels to the right, it sees a completely different string of numbers and has to learn “what a cup looks like” all over again. Shuffle all the pixels by one fixed rule and retrain, and it learns just as well, which shows it never used the information about which pixels are neighbours.

这两个毛病其实是一回事：全连接什么都不假设，所以一切都得从数据里学。如果我们事先知道数据有某种结构，比如图像里相邻的像素才相关、同一个东西出现在哪儿都长一个样，就可以把这个知识直接写进连接方式里，省下大量的参数和数据。后面几种结构做的都是这件事。全连接层本身并没有被淘汰：输入本来就是一小串数的时候（比如机械臂的关节角），它是首选；它也是所有大网络里的零件，Transformer 的每一层里都有一个。The two problems are really one: a fully connected layer assumes nothing, so everything must be learned from data. If we know in advance that the data has some structure, for example that only neighbouring pixels in an image are related and that the same thing looks the same wherever it appears, we can write that knowledge straight into the way things are connected and save a great deal of parameters and data. The architectures that follow all do exactly this. Fully connected layers have not gone away: when the input is just a short string of numbers (such as a robot arm’s joint angles) they are the first choice, and they are a component of every large network; every Transformer layer contains one.

第 2 步 · 卷积Step 2 · Convolution

只看邻居，到处共用Look only at neighbours, share everywhere

机器人的相机每秒拍几十张图，要在图里找到杯子。关于图像，有两件事我们事先就知道。第一，一个像素是什么，主要看它周围的像素，离得远的像素关系不大，这叫局部性。第二，杯子在图的左边还是右边，长得都一样，这叫平移不变。卷积层把这两件事直接写进了连接方式：每个输出只连输入里的一小块（比如 3 × 3），并且图上所有位置都用同一组权重。这一小块权重叫卷积核（kernel），也叫滤波器。A robot’s camera takes dozens of images per second, and we want to find the cup in them. We know two things about images in advance. First, what a pixel shows depends mostly on the pixels around it, and far-away pixels matter little; this is called locality. Second, a cup looks the same whether it is on the left or the right of the image; this is called translation invariance. A convolution layer writes both straight into its connections: each output connects to only a small patch of the input (say 3 × 3), and every position in the image uses the same set of weights. This small patch of weights is called a kernel, also known as a filter.

y[i, j] = Σu Σv k[u, v] · x[i + u, j + v] + b

输出图第 i 行第 j 列的值是这样算的：把卷积核盖在输入图上，中心对准 (i, j)；盖住的 3 × 3 = 9 个像素，各乘卷积核上对应的数，加起来，再加偏置 b。然后把卷积核挪到下一个位置，再算一遍。The value in row i, column j of the output image is computed like this: lay the kernel over the input image with its centre on (i, j); multiply each of the 3 × 3 = 9 covered pixels by the matching number in the kernel, add them up, and add the bias b. Then move the kernel to the next position and do it again.

只看 3 × 3，用的是局部性：判断这里有没有一条边，看周围一圈就够了。所有位置共用同一个 k，用的是平移不变：竖边在左上角和在右下角是同一种东西，没必要学两遍。两条加起来，一层的权重从"输入个数 × 输出个数"降到 9 个；而且网络在一个地方学会认竖边，在所有地方就都会认了。Looking at only 3 × 3 uses locality: to tell whether there is an edge here, the surrounding ring is enough. Sharing one k across all positions uses translation invariance: a vertical edge in the top left and one in the bottom right are the same kind of thing, so there is no need to learn it twice. Together they cut a layer’s weights from “inputs × outputs” to 9, and once the network learns to recognise vertical edges in one place, it recognises them everywhere.

真实的卷积层，输入有很多张图叠在一起，每张叫一个通道（channel）：彩色照片有红、绿、蓝 3 个通道，网络中间的层常有 64 个、256 个。这时一个卷积核是 3 × 3 × Cin 个数（Cin 是输入的通道数），一层有 Cout 个卷积核，输出 Cout 个通道。参数一共 3 × 3 × Cin × Cout 个，再加 Cout 个偏置，和图有多大无关：64 个通道进、64 个出，是 3.7 万个；同样大小（56 × 56 × 64）的全连接层要 400 亿个。另外，严格地说这个公式叫"互相关"，数学上的卷积要先把卷积核翻转 180°；但卷积核反正是学出来的，翻不翻都一样，深度学习里统一叫卷积。In a real convolution layer the input is many images stacked together, each called a channel: a colour photo has 3 channels (red, green, blue), and layers inside a network often have 64 or 256. Then one kernel holds 3 × 3 × Cin numbers (Cin is the number of input channels), and a layer has Cout kernels, producing Cout output channels. That makes 3 × 3 × Cin × Cout parameters plus Cout biases, regardless of the image size: 64 channels in and 64 out is 37 thousand; a fully connected layer of the same size (56 × 56 × 64) would need 40 billion. Also, strictly speaking this formula is a “cross-correlation”; a mathematical convolution flips the kernel by 180° first. Since the kernel is learned anyway, flipping makes no difference, and deep learning calls both convolution.

In a convolutional network the kernel’s numbers are learned, and each layer has dozens or hundreds of kernels, each looking for its own pattern. Also, when the input shifts by one cell, the output shifts by one cell too and keeps its shape. This property is called translation equivariance: wherever a pattern appears, the response appears there. It is not the same as the “translation invariance” from the start of this step: invariance describes the data (a moved cup is still a cup), equivariance describes the convolution layer (move the input and the output moves with it). Because convolution is equivariant, the network can recognise the cup wherever it is when it finally sums the whole image up into one label.

叠起来，才看得到整个杯子Stack layers to see the whole cup

一个 3 × 3 的卷积核只看得到 3 × 3 个像素，可要认出杯子，得看到整个杯子。办法是叠层：第二层的每个点看第一层的 3 × 3 个点，而第一层的每个点又各看原图的 3 × 3，合起来就是原图的 5 × 5。一个点最终能看到的原图范围，叫它的感受野（receptive field）。A 3 × 3 kernel sees only 3 × 3 pixels, but recognising a cup means seeing the whole cup. The way out is stacking: each point of the second layer looks at 3 × 3 points of the first layer, and each of those looks at 3 × 3 pixels of the original image, which together cover 5 × 5 of the original. The area of the original image that a point can ultimately see is called its receptive field.

叠深了：残差连接Going deeper: residual connections

既然多叠几层就看得更远、认得更抽象，为什么不叠 100 层？早期的深网络先碰到的是梯度问题：第 1 步说过，传回某一层的梯度，是从最后一层往回一路上局部斜率的乘积，层数一多，几十个斜率乘在一起，很容易越乘越小，或者越乘越大。好的初始化和归一化（下面会讲）基本压住了这个问题。可 2015 年的 ResNet 论文发现，就算梯度大小正常，普通的卷积网络叠到二三十层以后，再加深反而更差，而且不是因为死记硬背：连训练集上的误差都更高了。论文的解释是深网络难以优化：哪怕某几层什么都不用做，它们也很难把权重学成"原样输出"。残差连接对这两个问题都有帮助。If stacking more layers lets a network see further and recognise more abstract things, why not stack 100? Early deep networks first ran into the gradient problem: as step 1 showed, the gradient reaching a layer is the product of the local slopes along the way back from the last layer, and with dozens of slopes multiplied together it easily shrinks towards zero or blows up. Good initialization and normalization (covered below) largely tamed that. But the 2015 ResNet paper found that even with healthy gradients, ordinary convolutional networks got worse once they went beyond twenty or thirty layers, and not because of memorisation: even the error on the training set went up. The paper’s explanation is that deep networks are hard to optimise: even if some layers have nothing to do, they struggle to learn weights that pass their input through unchanged. Residual connections help with both problems.

hl+1 = hl + F(hl)

第 l + 1 层的输出，等于第 l 层的输出原样抄过来，再加上这一层新算出的一个"修改量" F(hl)。The output of layer l + 1 equals the output of layer l copied straight over, plus a “correction” F(hl) newly computed by this layer.

普通网络每层都要把输入整个重算一遍：hl+1 = F(hl)。加上"原样抄过来"这条近路以后，每层的局部斜率不再只是 F 的斜率，而是"1 + F 的斜率"：就算 F 的斜率很小，梯度也能沿着"1"那条路原封不动地传回去。如果某一层没什么可做，把 F 学成 0 就行，这层就成了"什么都不改"；普通网络想做到这一点，得把权重精确地学成"原样输出"，难得多。In an ordinary network every layer recomputes its whole input: hl+1 = F(hl). With the “copy it straight over” shortcut added, each layer’s local slope is no longer just F’s slope but “1 + F’s slope”: even if F’s slope is tiny, the gradient can travel back along the “1” path untouched. And if a layer has nothing to do, it just learns F = 0 and becomes “change nothing”; for an ordinary network to do that, it must learn weights that pass the input through exactly, which is much harder.

每一层不用从头重写，只要在上一层的基础上改一点。就像改文章：在原稿上批注修改，比每一轮都在白纸上重写容易，也不容易把原来好的地方改坏。No layer has to rewrite everything from scratch; it only edits what the previous layer produced. 普通网络，假如每层让梯度乘 0.9：30 层以后剩 0.930 ≈ 0.04，60 层以后剩 0.960 ≈ 0.002。每层乘 1.1：30 层以后变成 1.130 ≈ 17。残差网络每层乘的是"1 加一个小数"（这个小数可正可负），比如 1 + 0.01：60 层以后是 1.0160 ≈ 1.8，还在正常范围。In an ordinary network, suppose each layer multiplies the gradient by 0.9: after 30 layers 0.930 ≈ 0.04 is left, and after 60 layers 0.960 ≈ 0.002. With 1.1 per layer, after 30 layers it becomes 1.130 ≈ 17. In a residual network each layer multiplies by “1 plus a small number” (which can be positive or negative), say 1 + 0.01: after 60 layers that is 1.0160 ≈ 1.8, still in a healthy range.

ResNet（He 等 2016）用残差连接训练了 152 层的网络，拿下 2015 年 ImageNet 比赛第一名。今天几乎所有深的网络都有残差连接：后面的 Transformer 里有，扩散模型用的 U-Net 每一级也是残差块。和它配套的还有归一化（BatchNorm、LayerNorm）：把每层算出的数重新缩放到差不多大，目的也是不让信号和梯度越传越大或越传越小。ResNet (He et al. 2016) used residual connections to train a 152-layer network and won the 2015 ImageNet challenge. Today almost every deep network has residual connections: the Transformer later on this page has them, and so does every level of the U-Nets used in diffusion models. A companion part is normalization (BatchNorm, LayerNorm): it rescales the numbers each layer produces to a similar size, with the same aim of keeping signals and gradients from growing or shrinking as they pass through.

卷积好在哪What convolution is good at

  • 参数少，而且和图多大无关：同一个卷积核用遍全图Few parameters, and independent of the image size: one kernel is used across the whole image
  • 平移等变：一个图案在一处学会，处处都认得Translation equivariance: a pattern learned in one place is recognised everywhere
  • 每隔几层缩小一次，计算量小、速度快，适合机器人上的实时视觉；数据不多时也学得不错Shrinking every few layers keeps computation small and fast, which suits real-time vision on robots; it also learns well without much data

坑在哪Where it breaks

  • 看远处只能靠叠层，真正起作用的范围比理论上小得多，图两头的东西很难直接联系Seeing far relies on stacking layers, the area that really matters is much smaller than in theory, and things at opposite ends of an image are hard to relate directly
  • 假设是写死的：只适合排成规则网格的数据（图像、声音的频谱、等间隔采样的时间序列，长度不限），点云、图这类不规则的数据不能直接用The assumptions are hard-wired: it only suits data laid out on a regular grid (images, audio spectrograms, time series sampled at even intervals, of any length); irregular data such as point clouds and graphs does not fit directly
  • 数据极多时，"只看邻居"这个硬性假设可能变成上限（第 5 步的 ViT）With huge amounts of data, the hard assumption of “neighbours only” can become a ceiling (ViT in step 5)

第 3 步 · 循环Step 3 · Recurrence

带着记忆，一步一步读Reading step by step, with a memory

机器人收到的数据往往是一串：每一刻的相机画面、关节角、力传感器的读数。顺序很重要，而且现在该做什么，常常取决于很久以前看到的东西。比如：机器人看到桌上有个杯子，然后伸手过去，手臂挡住了相机。杯子还在吗？此刻的画面里已经没有杯子了，答案只能从"记忆"里来。The data a robot receives often comes as a sequence: camera images, joint angles and force-sensor readings at each moment. Order matters, and what to do now often depends on something seen long ago. For example: the robot sees a cup on the table, then reaches out, and its arm blocks the camera. Is the cup still there? The current image no longer shows it, so the answer can only come from “memory”.

循环神经网络（RNN，recurrent neural network）就是为这种数据设计的：用同一个小网络，按时间一步一步地读。每一步除了读这一刻的输入，还读上一步留下的"记忆"，算出新的记忆，再交给下一步。A recurrent neural network (RNN) is designed for this kind of data: one small network reads the sequence step by step in time. At each step it reads not only this moment’s input but also the “memory” left by the previous step, computes a new memory, and hands it on to the next step.

ht = tanh( W ht−1 + U xt + b )

这一刻的记忆 ht 是这样算的：上一刻的记忆 ht−1 乘权重 W，这一刻的输入 xt 乘权重 U，两个加起来，再加偏置 b，最后过 tanh，压到 −1 到 1 之间。每一刻用的都是同一组 W、U、b。This moment’s memory ht is computed like this: multiply the previous memory ht−1 by the weight W and this moment’s input xt by the weight U, add the two, add the bias b, and finally pass it through tanh to squash it into −1 to 1. Every moment uses the same W, U and b.

序列可长可短，没法给每个时刻准备一套权重，所以所有时刻共用同一组。这和卷积在所有位置共用卷积核是同一个想法，只是从"在空间里平移"换成了"在时间里平移"。想让现在依赖过去，又不想每一步都把整个过去重读一遍，就把过去压缩成一串固定长度的数 h，一步步往下传。tanh 把记忆限制在 −1 到 1 之间，免得一步步乘下去变成无穷大。Sequences can be long or short, so there is no way to prepare a separate set of weights for every moment; all moments share one set. This is the same idea as convolution sharing its kernel across all positions, just with “shifting in space” replaced by “shifting in time”. To let the present depend on the past without rereading the whole past at every step, the past gets compressed into a fixed-length string of numbers h that is passed along step by step. tanh keeps the memory between −1 and 1 so that it cannot grow to infinity as it is multiplied step after step.

记忆只有一个数，W = 0.8，U = 1，b = 0。第 3 步看到杯子（x = 1），其他时刻都没看到（x = 0）。h3 = tanh(0.8 × 0 + 1) = tanh(1) ≈ 0.76。之后没有输入：h4 = tanh(0.8 × 0.76) ≈ 0.54，h5 = tanh(0.8 × 0.54) ≈ 0.41……每一步乘 0.8、再过 tanh，越来越小，到第 30 步只剩 0.001。The memory is a single number, W = 0.8, U = 1, b = 0. After that there is no input: h4 = tanh(0.8 × 0.76) ≈ 0.54, h5 = tanh(0.8 × 0.54) ≈ 0.41… Each step multiplies by 0.8 and passes through tanh, so it keeps shrinking; by step 30 only 0.001 is left.

训练时，梯度要沿着时间一步步往回传（这叫随时间反向传播，BPTT），每往回一步，就要乘一次这一步的局部斜率：W 乘上 tanh 的斜率。这和第 2 步里深网络的问题一模一样：一个 30 步的序列，就相当于一个 30 层的网络，乘几十次，梯度不是消失就是爆炸。所以普通的循环网络很难学会"隔很久的依赖"（Bengio 等 1994）。During training the gradient has to travel back through time step by step (this is called backpropagation through time, BPTT), and each step back multiplies by that step’s local slope: W times the slope of tanh. This is exactly the problem of deep networks in step 2: a 30-step sequence is like a 30-layer network, and after dozens of multiplications the gradient either vanishes or explodes. That is why ordinary recurrent networks struggle to learn dependencies that span a long time (Bengio et al. 1994).

解决办法和残差连接很像：给记忆开一条不用每步都重新计算的近路。LSTM（长短期记忆网络，Hochreiter、Schmidhuber 1997）多存了一份记忆 c，并用几个"门"控制它：The fix is much like a residual connection: give the memory a shortcut that is not recomputed at every step. The LSTM (long short-term memory, Hochreiter, Schmidhuber 1997) keeps an extra memory c and controls it with a few “gates”:

ct = ft ⊙ ct−1 + it ⊙ c̃t

新的记忆 ct，等于旧的记忆 ct−1 乘遗忘门 ft，再加上这一刻的新内容 c̃t 乘输入门 it。两个乘法都是逐个对应相乘。The new memory ct equals the old memory ct−1 times the forget gate ft, plus this moment’s new content c̃t times the input gate it. Both multiplications are element by element.

普通 RNN 的毛病，出在每一步都要乘一个矩阵、再过一次 tanh。这里的旧记忆只乘一个 0 到 1 之间的数 f，然后直接加上新内容，中间没有矩阵，也没有 tanh。f 接近 1 时，记忆和梯度几乎原样传下去，这和残差连接 h + F(h) 是同一个思路。门也不是固定的数，而是网络根据这一刻的输入和上一刻的输出现算出来的：该记的时候把遗忘门开大，该忘的时候关小。The trouble with an ordinary RNN comes from multiplying by a matrix and passing through tanh at every step. Here the old memory is only multiplied by a number f between 0 and 1, and the new content is added directly, with no matrix and no tanh in between. With f close to 1, the memory and the gradient pass along almost unchanged: the same idea as the residual connection h + F(h). The gates are not fixed numbers either; the network computes them from this moment’s input and the previous output: open the forget gate wide when something should be kept, close it when it should be dropped.

记忆不再每一步都重写一遍，而像一个带开关的储物柜：平时原样放着，需要的时候才放进新东西，或者清掉旧东西。The memory is no longer rewritten at every step; it is more like a locker with switches: things stay as they are, and only when needed is something new put in or something old cleared out.

The original 1997 LSTM actually had no forget gate, which amounts to f always being 1: the memory is kept as it is and only added to; the forget gate was added by Gers et al. 2000, so that the network can also learn to clear out stale memories. The GRU (Cho et al. 2014) is a simplified version with only two gates and works about as well. Until the Transformer arrived in 2017, the LSTM was the workhorse of speech recognition and machine translation.

循环网络还有一个结构上的问题：必须按顺序算。第 100 步要等第 99 步算完，没法让 GPU 同时算所有时刻，训练长序列很慢。而且所有过去的信息都得挤进一串固定长度的数里，序列越长，挤得越厉害。第 5 步的注意力就是冲着这两点来的：不压缩，每一步都直接回头看所有的过去，所有位置还能同时算。Recurrent networks have one more structural problem: they must be computed in order. Step 100 has to wait for step 99, so a GPU cannot work on all moments at once, and training on long sequences is slow. And all past information has to be squeezed into a fixed-length string of numbers; the longer the sequence, the tighter the squeeze. Attention in step 5 targets both points: no compression, every step looks straight back at the whole past, and all positions can be computed at the same time.

不过，循环的想法没有过时。运行的时候，循环网络每来一个新输入只要算一步，计算量和内存都不随序列变长而增加，这对一直开着的机器人很有吸引力。近年的状态空间模型，比如 Mamba（Gu、Dao 2023），把门的思路和能并行训练的结构结合了起来，在长序列上可以和 Transformer 一较高下。Still, the recurrent idea is not obsolete. When running, a recurrent network needs just one step of computation per new input, and neither computation nor memory grows with the length of the sequence, which is very attractive for a robot that is always on. Recent state-space models such as Mamba (Gu, Dao 2023) combine the gating idea with a structure that can be trained in parallel, and hold their own against Transformers on long sequences.

  • 序列多长都行，参数量不变Sequences of any length, with the same number of parameters
  • 每来一个新输入只算一步，内存不随时间增长，适合一直在线运行的系统Each new input costs one step and memory does not grow over time, which suits systems that run online continuously
  • 时间上也是"到处共用"：同一个规律，出现在序列的哪个位置都认得“Shared everywhere” in time as well: the same pattern is recognised wherever it appears in the sequence

坑在哪Where it breaks

  • 必须按顺序算，训练时没法并行，慢Must be computed in order, so training cannot be parallelised and is slow
  • 梯度要一步步往回乘，普通 RNN 记不久；LSTM 好得多，但几百步以上仍然吃力The gradient is multiplied step by step on the way back, so a plain RNN forgets quickly; an LSTM does much better but still struggles beyond a few hundred steps
  • 所有过去都挤进一串固定长度的数里，信息会丢The entire past is squeezed into a fixed-length string of numbers, so information gets lost

第 4 步 · U-NetStep 4 · U-Net

缩小看全局，跳连补细节Shrink to see the whole, skip to restore the details

有些任务要的输出不是一个标签，而是一整张图：每个像素是杯子还是桌子（这叫图像分割），或者把一张带噪声的图还原成干净的图（去噪）。这类任务同时要两样东西：看得广，才知道这一片是个杯子；看得细，才能把杯子的边缘画准到每一个像素。Some tasks need not a label but a whole image as output: whether each pixel is cup or table (called image segmentation), or restoring a noisy image to a clean one (denoising). Such tasks need two things at once: a wide view, to know that this region is a cup, and a fine view, to draw the cup’s edge accurately to the pixel.

第 2 步讲过，卷积网络靠一级级缩小来看得广，代价是位置细节变模糊。U-Net（Ronneberger 等 2015）的办法很直接：先像普通卷积网络那样一级级缩小，这一半叫编码器；再一级级放大回原来的大小，这一半叫解码器；同时在每一级，把编码器这一级的特征图直接送到解码器的同一级，这叫跳连（skip connection）。画出来左边往下、右边往上，像一个字母 U，名字就是这么来的。它不是一种新的层，里面全是卷积，它是一种排法。As step 2 showed, convolutional networks get a wide view by shrinking level by level, at the price of blurring where things are. U-Net (Ronneberger et al. 2015) solves this directly: first shrink level by level like an ordinary convolutional network, a half called the encoder; then enlarge level by level back to the original size, a half called the decoder; and at every level, send the encoder’s feature map straight across to the same level of the decoder, which is called a skip connection. Drawn out, the left side goes down and the right side comes up like the letter U, hence the name. It is not a new kind of layer, it is all convolutions; it is an arrangement.

decl = Conv( [ Up(decl+1), encl ] )

解码器第 l 级的特征图是这样算的：把下一级（更小的那一级）的解码结果放大一倍，和编码器同一级的特征图 encl 拼在一起，再过几层卷积。The decoder’s feature map at level l is computed like this: enlarge the decoded result from the level below (the smaller one) by a factor of two, join it with the encoder’s feature map encl at the same level, and pass the result through a few convolution layers.

放大回来的 Up(decl+1) 知道"这是什么"，因为它来自看得最广的底层，但位置是糊的；encl 是缩小之前的特征图，位置是准的，但只看到了局部。两份拼在一起，后面的卷积就能同时用上"这一片是杯子"和"边缘就在这一格"。用拼接而不是相加，是把选择权交给后面的卷积：两份信息各用多少、怎么组合，让它自己学。The enlarged Up(decl+1) knows “what this is”, because it comes from the bottom level with the widest view, but its positions are blurry; encl is the feature map from before shrinking, with accurate positions but only a local view. Joined together, the following convolutions can use both “this region is a cup” and “the edge is right in this cell”. Joining instead of adding leaves the choice to the convolutions that follow: how much of each to use and how to combine them is for them to learn.

64 × 64 的图缩小 3 次，最底下是 8 × 8，每一格对应原图的 8 × 8 个像素。在那一级每叠一层 3 × 3 卷积，视野就多出 2 × 8 = 16 个像素（第 2 步的感受野公式），叠 4 层就是 8 + 4 × 16 = 72，超过了整张图；不缩小的话，要叠 32 层。可那里一共只有 8 × 8 = 64 个位置：不加跳连，放大回 64 × 64 以后，每 8 × 8 个像素只能共用一份信息，边缘画不准。Shrink a 64 × 64 image 3 times and the bottom level is 8 × 8, each cell covering 8 × 8 pixels of the original. Each 3 × 3 convolution layer at that level widens the view by 2 × 8 = 16 pixels (the receptive-field formula from step 2), so 4 layers reach 8 + 4 × 16 = 72, more than the whole image; without shrinking it would take 32 layers. But there are only 8 × 8 = 64 positions down there: without skip connections, after enlarging back to 64 × 64, every block of 8 × 8 pixels has to share one piece of information, and edges cannot be drawn accurately.

跳连有两种写法：U-Net 是拼接，第 2 步的残差连接是相加。目的都是给信息和梯度一条近路：残差连接跳过一两层，U-Net 的跳连跳过整个"缩小再放大"的过程。U-Net 后来成了很多扩散模型里的去噪网络（第 6 步），原因正是这里讲的：去噪既要知道"这是什么"，又要把每个像素都还原到位。Skip connections come in two forms: U-Net joins, the residual connection of step 2 adds. Both aim to give information and gradients a shortcut: a residual connection skips one or two layers, while U-Net’s skip connections skip the whole “shrink, then enlarge” journey. U-Net later became the denoising network inside many diffusion models (step 6), for exactly the reason given here: denoising needs to know “what this is” and also to restore every pixel to its place.

真正的 U-Net 比这复杂得多：每一级都有好几层能学的卷积，跳连送过去的也不只是"细节"，而是那一级的全部特征图，由解码器里的卷积决定怎么用。但道理是一样的：缩小换来对全局的理解，跳连把位置细节还回来。U-Net 最早用于显微镜图像的细胞分割，只用了 30 张标注好的图像（再加上大量的数据增强：把图随机旋转、拉伸、变形，造出更多训练样本）就训练得很好；今天它是医学图像分割的标准结构，也是很多扩散模型里的去噪网络。A real U-Net is much more elaborate: every level has several learnable convolution layers, and the skip connections carry not just the “detail” but that level’s full feature maps, which the decoder’s convolutions decide how to use. The principle is the same, though: shrinking buys an understanding of the whole, and skip connections give back the positional detail. U-Net was first used to segment cells in microscope images, and trained well on just 30 annotated images (plus heavy data augmentation: randomly rotating, stretching and deforming the images to create more training examples); today it is the standard architecture for medical image segmentation and the denoising network in many diffusion models.

U-Net 好在哪What U-Net is good at

  • 输出和输入一样大，适合"每个像素都要一个答案"的任务：分割、去噪、深度估计The output is the same size as the input, which suits tasks that need an answer for every pixel: segmentation, denoising, depth estimation
  • 既有底层的全局信息，又有跳连带回来的细节，数据不多时也训练得好It has both global information from the bottom and the detail brought back by skip connections, and trains well even without much data
  • 里面全是卷积，继承了卷积的所有好处：参数少，图多大都能用It is all convolutions and inherits all their advantages: few parameters, any image size

坑在哪Where it breaks

  • 说到底还是卷积：看全局要靠缩小很多次，图上相距很远的东西之间联系弱In the end it is still convolution: a global view depends on shrinking many times, and distant parts of the image are only weakly connected
  • 跳连会把噪声和无关的细节一起送过去，要靠后面的卷积学会筛选Skip connections carry noise and irrelevant detail across too, and the convolutions after them must learn to filter it
  • 编码器每一级的特征图都要留着等解码器用，占显存（GPU 上的内存）Every encoder level’s feature maps must be kept until the decoder uses them, which takes up GPU memory

第 5 步 · 注意力和 TransformerStep 5 · Attention and Transformers

连谁、连多重，按内容现算Who connects to whom, and how strongly, computed from the content

卷积只看邻居，循环只看上一刻。可很多时候，相关的东西离得很远：一句话的主语，和几十个词以后的动词；画面左边的杯子，和右边的杯盖；机器人现在的动作，和一分钟前听到的指令。卷积要叠很多层才能把它们连起来，循环要一步步传过去，路上信息会丢。注意力（attention）换了一个思路：每个位置直接和所有位置相连，但每条连线多粗，不是固定的权重，而是按内容现算出来的。Convolution looks only at neighbours, recurrence only at the previous moment. Yet related things are often far apart: the subject of a sentence and its verb dozens of words later; a cup on the left of the image and its lid on the right; the robot’s current action and an instruction it heard a minute ago. Convolution needs many stacked layers to connect them, and recurrence has to pass the information along step by step, losing some on the way. Attention takes a different approach: every position connects directly to every position, but how thick each connection is comes not from a fixed weight but from a calculation on the content.

注意力处理的是一串 token：每个 token 是一串数，可以代表一个词、图像里的一小块、机器人某一时刻的状态。注意力最早用在机器翻译里，帮循环网络回头查原文（Bahdanau 等 2014）；2017 年的 Transformer（Vaswani 等）干脆把循环全拿掉，只用注意力。Attention works on a sequence of tokens: each token is a string of numbers that can stand for a word, a small patch of an image, or the robot’s state at one moment. Attention was first used in machine translation, to let a recurrent network look back at the source sentence (Bahdanau et al. 2014); the 2017 Transformer (Vaswani et al.) dropped recurrence entirely and used attention alone.

aij = softmaxj( qi · kj ∕ √d )outi = Σj aij vj

第 i 个 token 的查询 qi，和每个 token j 的键 kj 做点积，得到一个匹配分数；除以 √d，再对所有 j 做 softmax，变成一组加起来等于 1 的权重 aij。第 i 个 token 的输出，就是所有 token 的值 vj 按这组权重的加权平均。Take the dot product of token i’s query qi with each token j’s key kj to get a match score; divide by √d, then apply softmax over all j to turn the scores into weights aij that add up to 1. Token i’s output is the average of all the tokens’ values vj, weighted by these weights.

卷积和循环把"谁和谁混合、混合多少"写死在结构里；注意力让数据自己决定：先说"我在找什么"（q），再看每个人"我有什么"（k），越对得上，就从它那里拿越多的内容（v）。点积是衡量两串数像不像的最简单的办法。softmax 把分数变成加起来是 1 的正数，这样输出是一个平均，不会因为 token 变多就变大。除以 √d，是因为点积会随 d 变大：如果 q 和 k 的每个数平均是 0、方差是 1，点积是 d 个乘积之和，标准差是 √d；除以 √d，正好把分数拉回 1 左右。不除的话，d 一大，softmax 就变得极端，几乎只选一个，梯度也接近 0。把 q、k、v 分开，是因为同一个 token "想找什么"和"能提供什么"不是一回事，分开学更灵活。Convolution and recurrence hard-wire “who mixes with whom, and how much” into the structure; attention lets the data decide: first say “what I am looking for” (q), then check what each token “has to offer” (k), and the better the match, the more content (v) you take from it. The dot product is the simplest way to measure how alike two strings of numbers are. Softmax turns the scores into positive numbers that add up to 1, so the output is an average and does not grow just because there are more tokens. Dividing by √d is needed because dot products grow with d: if each number in q and k has mean 0 and variance 1, the dot product is a sum of d products and has standard deviation √d, so dividing by √d brings the scores back to a size of about 1. Without it, a large d makes softmax extreme: it picks almost a single token, and its gradients approach 0. q, k and v are kept separate because what a token is looking for and what it can offer are different things, and learning them separately is more flexible.

每个 token 都要和每个 token 算一次分数：N 个 token 就是 N × N 个分数。token 数翻一倍，算分数这部分的计算量翻四倍（直接存下这张 N × N 的表的话，显存也翻四倍），而 MLP 等其余部分只翻一倍；token 一多，平方这一项就占了大头，这是 Transformer 处理长序列和高分辨率图像时的主要瓶颈。还有一点：这个公式里完全没有"位置"。把 token 的顺序打乱，每个 token 得到的输出一点不变，只是跟着换了位置。所以还要另外告诉它每个 token 排在第几个，这就是下面交互里的位置编码。Every token computes a score with every token: N tokens mean N × N scores. Double the tokens and the scoring part costs four times as much (and so does memory, if that N × N table is stored directly), while the MLP and the other parts only double; with many tokens the quadratic term dominates, and this is the main bottleneck when Transformers handle long sequences and high-resolution images. One more thing: this formula contains no notion of “position” at all. Shuffle the tokens and each token’s output stays exactly the same, it just moves along with the token. 注意力只看内容，不知道顺序，所以要把"我在第几个"写进每个 token 的数里。用正弦余弦有三个好处：值都在 −1 到 1 之间，不会因为位置大了就变得很大；频率不同的好几对组合起来，每个位置的编码都不一样；两个位置的编码做点积，sin ωp · sin ωp′ + cos ωp · cos ωp′ = cos ω(p − p′)，只取决于它们相距多远（p′ 是另一个位置），所以网络很容易学会"关注离我近的"。Attention only looks at content and knows nothing about order, so “where I sit” has to be written into each token’s numbers. Sines and cosines have three advantages: their values stay between −1 and 1 and do not blow up at large positions; several pairs with different frequencies together give every position a different code; and the dot product of two positions’ codes, sin ωp · sin ωp′ + cos ωp · cos ωp′ = cos ω(p − p′), depends only on how far apart they are (p′ is the other position), so the network can easily learn to “attend to things near me”.

现在很多模型改用可以学的位置编码，或者旋转位置编码（RoPE，Su 等 2021，把位置直接"转"进 q 和 k 里），道理都一样：把顺序信息补回给注意力。图像上的 Transformer 也要给每个小块加上它在图里的位置。Many models now use learned position encodings instead, or rotary position encodings (RoPE, Su et al. 2021, which “rotates” the position straight into q and k). 一个完整的 Transformer 层，是注意力加上第 1 步的全连接网络，再用上第 2 步的残差连接：A complete Transformer layer is attention plus the fully connected network from step 1, with the residual connections from step 2:

x ← x + Attn( LN(x) )x ← x + MLP( LN(x) )

第一行：先做层归一化，再让所有 token 互相看一遍（注意力），把看到的加回到原来的 x 上。第二行：再做一次层归一化，让每个 token 各自过一个小的全连接网络，结果也加回 x 上。First line: apply layer normalization, then let all tokens look at each other (attention), and add what they saw back onto the original x. Second line: apply layer normalization again, pass each token through a small fully connected network on its own, and add the result back onto x as well.

注意力负责在 token 之间搬运信息，但它本质上是加权平均，"弯一下"的能力很弱；MLP 负责在每个 token 内部加工信息，提供非线性。两步交替，一层层叠下去。两步都是残差的写法（x + …），所以能叠得很深；层归一化把每个 token 的数缩放到差不多的大小，让训练更稳。Attention moves information between tokens, but at heart it is a weighted average, with little power to “bend”; the MLP processes information inside each token and supplies the nonlinearity. The two steps alternate, stacked layer upon layer. Both are written as residuals (x + …), so the stack can go very deep; layer normalization rescales each token’s numbers to a similar size, which keeps training stable.

多头的意思是：一个头只算一组权重，只能表达一种"关注谁"；多个头可以同时关注不同的东西，比如一个看颜色、一个看位置。上面的交互每次只看一个头。注意力也能在两组 token 之间做：查询来自一组（比如图像），键和值来自另一组（比如文字），这叫交叉注意力；同一组 token 互相看，叫自注意力。另外，这里先归一化、再注意力的写法（Pre-LN）是现在通用的；2017 年的原版把 LN 放在相加之后，层数多了不太好训练。Multi-head means this: one head computes only one set of weights, so it can express only one notion of “whom to attend to”; several heads can attend to different things at once, for example one by colour and one by position. The interactive above shows one head at a time. Also, normalizing first and then applying attention, as written here (Pre-LN), is the common form today; the 2017 original put LN after the addition, which made deep stacks harder to train.

同样的 Transformer 层，换一种切 token 的办法，就能处理各种数据。ViT（Dosovitskiy 等 2020）把图像切成 16 × 16 像素的小块，每块当一个 token。先在 3 亿张图上训练（这叫预训练，之后再用目标任务的数据接着训练，叫微调），它就超过了当时最好的卷积网络；可如果只用 130 万张图（ImageNet）训练，它不如同样大小的卷积网络：它没有"只看邻居"这个先验，得从数据里自己学出来。GPT 系列把文字切成 token，每个 token 只许看它前面的 token，一个一个地预测下一个。机器人也一样：相机画面、语言指令、关节状态都切成 token，放进同一个 Transformer，第 7 步会看到具体的例子。The same Transformer layer handles all kinds of data once you change how the tokens are cut. ViT (Dosovitskiy et al. 2020) cuts an image into patches of 16 × 16 pixels and treats each patch as a token. Trained first on 300 million images (this is called pre-training; training further on the target task’s data afterwards is called fine-tuning), it beat the best convolutional networks of the time; but trained on only 1.3 million images (ImageNet), it falls short of convolutional networks of the same size: it lacks the “neighbours only” prior and has to learn it from data. The GPT series cuts text into tokens, lets each token look only at the tokens before it, and predicts the next one, one at a time. Robots are no different: camera images, language instructions and joint states are all cut into tokens and fed into the same Transformer; step 7 shows concrete examples.

注意力好在哪What attention is good at

  • 一层之内，任意两个位置都能直接交换信息，远近一样Within a single layer, any two positions can exchange information directly, near or far
  • 连谁、连多重按内容现算，同一个结构能处理文字、图像、动作，以及它们的混合Who connects to whom, and how strongly, is computed from the content, so one structure handles text, images, actions and mixtures of them
  • 所有位置可以同时算，很适合 GPU，能做得非常大；数据越多，优势越明显All positions can be computed at once, which suits GPUs and lets models grow very large; the more data, the bigger the advantage

坑在哪Where it breaks

  • 注意力的计算量随 token 数的平方增长，长序列、高分辨率的图都很贵Attention’s computation grows with the square of the number of tokens, so long sequences and high-resolution images are expensive
  • 先验最少：本身不知道顺序和远近，要加位置编码；数据少时不如卷积The fewest priors: it knows nothing of order or distance by itself and needs position encodings; with little data it loses to convolution
  • 一个一个往外生成时，每一步都要回头看前面所有的 token，越往后越慢When generating one token at a time, every step has to look back at all previous tokens, so it gets slower the further it goes

扩散不是一种结构Diffusion is not an architecture

很多人把扩散模型和 CNN、Transformer 并列，当成又一种网络结构，其实不是。前面五步讲的都是网络长什么样：连谁、权重共不共享。扩散模型规定的是另外两件事：让网络学什么（训练目标），以及学好以后怎么用它生成东西（生成的过程）。至于里面的网络，可以是 U-Net，可以是 Transformer；在下面的小例子里，它甚至只是一个公式。Many people list diffusion models alongside CNNs and Transformers as yet another network architecture, but they are not one. The first five steps were all about what the network looks like: who connects to whom, and whether weights are shared. A diffusion model specifies two other things: what the network learns (the training objective), and how the trained network is used to generate things (the generation process). The network inside can be a U-Net or a Transformer; in the small example below it is just a formula.

扩散做的事是生成：从一堆例子（照片、示范动作）里学会它们的分布，再造出新的、像样的例子。思路是先学会去噪，再把去噪重复很多次（Sohl-Dickstein 等 2015；DDPM，Ho 等 2020）。先看训练时怎么造出带噪声的数据：What diffusion does is generation: learn the distribution of a pile of examples (photos, demonstrated actions) and then produce new, convincing examples. The idea is to learn to denoise first, then repeat the denoising many times (Sohl-Dickstein et al. 2015; DDPM, Ho et al. 2020). First, how training makes noisy data:

xt = √ᾱt · x0 + √(1 − ᾱt) · ε,  ε ∼ N(0, I)

第 t 步的带噪声数据 xt，等于原来的数据 x0 乘 √ᾱt，再加上一份标准高斯噪声 ε 乘 √(1 − ᾱt)。The noisy data at step t, xt, equals the original data x0 times √ᾱt, plus a sample of standard Gaussian noise ε times √(1 − ᾱt).

想让网络学会"从噪声变回数据"，先得有大量"带噪声的样子 → 原来的样子"这样的练习题。加噪声随手就能做，所以练习题要多少有多少。两个系数的平方加起来正好是 1，这样不管加到第几步，xt 的整体大小都差不多；加到最后，ᾱ 接近 0，xt 就是纯粹的标准高斯噪声。生成时就从这样的噪声出发。To teach a network to “turn noise back into data”, you first need lots of exercises of the form “noisy version → original”. Adding noise is trivial, so there can be as many exercises as you like. The squares of the two coefficients add up to exactly 1, so xt keeps roughly the same overall size whatever the step; at the end, ᾱ is close to 0 and xt is pure standard Gaussian noise. Generation starts from noise like that.

然后让网络学会反过来：看到 xt，猜出加进去的噪声。Then the network learns the reverse: given xt, guess the noise that was added.

随机拿一个数据 x0，随机选一个 t，随机抽一份噪声 ε，按上面的式子算出 xt；把 xt 和 t 交给网络 εθ，让它猜加进去的噪声；猜的和真的相差的平方，就是损失。对很多次这样的随机选择取平均。Pick a random data point x0, a random t and a random noise sample ε, and compute xt with the formula above; hand xt and t to the network εθ and let it guess the noise that was added; the squared difference between the guess and the truth is the loss. Average over many such random choices.

知道了加进去的噪声，就能把它减掉，算出原来的数据：x0 = (xt − √(1 − ᾱt) · ε) ∕ √ᾱt。所以"猜噪声"和"猜原来的数据"可以互相换算（两种损失只差一个随 t 变化的权重），DDPM 发现猜噪声生成的质量更好。把 t 也告诉网络，是因为噪声大小不同，该怎么猜也不同：噪声小时只要修修细节，噪声大时只能猜个大概。Once you know the noise that was added, you can subtract it and recover the original data: x0 = (xt − √(1 − ᾱt) · ε) ∕ √ᾱt. So “guess the noise” and “guess the original data” can be converted into each other (the two losses differ only by a weight that depends on t), and DDPM found that guessing the noise gives better samples. If the network guesses εθ = (0.1, −0.9), the loss is (0.2 − 0.1)² + (−1 + 0.9)² = 0.02. Recovering with its guess: x̂0 = ((0.85, −0.71) − 0.71 × (0.1, −0.9)) ∕ 0.71 ≈ (1.1, −0.1), not far from the true (1, 0). The little hat on x̂0 means “guessed”.

关键在这里：同一个 xt，可能来自好几个不同的 x0。用平方误差训练，网络学到的最好猜法，是所有可能答案的平均（平均平方误差在猜测等于平均值时最小：比如答案一半是 −1、一半是 1，猜 0 的平均误差是 1，猜 1 是 2）。噪声很大时，几乎什么都可能，最好的猜法就是"所有数据的平均"。所以生成不能一步到位，要一步步来：每走一步，噪声小一点，要平均的范围就小一点，最后落到一个具体的答案上。下面的交互里，把步数调成 1 就能看到。Here is the crux: the same xt could have come from several different x0. Trained with squared error, the best guess the network can learn is the average of all possible answers (the mean squared error is smallest when the guess equals the average: if the answer is −1 half the time and 1 half the time, guessing 0 gives an average error of 1, guessing 1 gives 2). When the noise is very large almost anything is possible, so the best guess is “the average of all the data”. That is why generation cannot jump there in one step and must go step by step: each step lowers the noise a little and narrows the range being averaged, until the result lands on one specific answer. Diffusion became popular in robotics precisely because of the “one step gives the average” effect in the interactive: in the same scene, demonstrations often show several equally correct ways to act, and direct regression (having the network output one action directly, trained with squared error) averages them into one wrong way; diffusion denoises step by step, and each sample lands on one of the ways (Diffusion Policy, Chi et al. 2023).

  • 能表示有好几个峰的分布，不会把几种做法平均成一种错的做法It can represent distributions with several peaks, instead of averaging several ways of acting into one wrong one
  • 训练稳：目标就是简单的平方误差，练习题可以自动造，要多少有多少Stable training: the objective is a simple squared error, and exercises are made automatically, as many as you want

  • 生成要走很多步，每一步都要把整个网络算一遍，比一次前向慢几十倍，对要实时控制的机器人是负担Generation takes many steps, each running the whole network once, dozens of times slower than a single forward pass, which is a burden for robots under real-time control
  • 步数少了，质量就下降（交互里看到了），所以有很多加速的办法：更好的走法、流匹配，或者再训练一个网络一步学会多步的结果（叫蒸馏）With fewer steps the quality drops (as the interactive showed), so there are many ways to speed it up: better stepping schemes, flow matching, or training another network to reach the result of many steps in one (called distillation)
  • 不直接告诉你"这个结果有多大可能"It does not directly tell you how likely a given result is

第 7 步 · 拼起来Step 7 · Putting it together

真实系统怎么组合这些积木How real systems combine these building blocks

真实的系统很少只用一种结构，而是按每一部分数据的特点挑积木：图像先过卷积，或者切成小块交给 Transformer；不同来源的信息用注意力融合；每个位置都要输出时用 U-Net；要生成好几种可能时，在外面套上扩散或流匹配。下面八个系统，从图像分类、语言模型到机器人策略，可以对照着看每一块为什么在那儿。Real systems rarely use just one architecture; they pick building blocks to suit each part of the data: images go through convolutions first, or get cut into patches for a Transformer; information from different sources is fused with attention; a U-Net is used when every position needs an output; and when several possible outputs must be generated, diffusion or flow matching is wrapped around the outside. For the eight systems below, from image classification and language models to robot policies, you can check why each block is where it is.

    • 融合不同来源的信息，几乎总用注意力。几个相机、一句指令、关节状态，都切成 token 放在一起，注意力不在乎 token 从哪来、有多少个。Information from different sources is almost always fused with attention. Where a system runs continuously or rolls forward step by step in imagination (as in Dreamer’s world model), “one computation per step” still pays off.

    回到开头的几个问题Back to the opening questions

    • 为什么有这么多种结构？每一层都是"混合，再弯一下"，不同结构只是混合的方式不同。选哪种，就是在选对数据的假设：假设对了，需要的数据和参数都少得多；假设错了，它就成了上限。Why are there so many architectures? Every layer is “mix, then bend”; architectures differ only in how they mix. Choosing one means choosing assumptions about the data: if the assumptions are right, you need far less data and far fewer parameters; if they are wrong, they become a ceiling.
    • 为什么现在到处都是 Transformer？数据和算力足够多时，少做假设、让数据自己说话反而更好；而且文字、图像、动作都能切成 token 放在一起，所有位置还能同时算。Why is everything a Transformer these days? With enough data and compute, making fewer assumptions and letting the data speak works better; and text, images and actions can all be cut into tokens and put together, with every position computed at once.
    • 卷积和循环过时了吗？没有。数据少、要实时、要在小芯片上跑时，卷积的先验很划算；一直在线、内存必须固定时，循环（以及 Mamba 这类状态空间模型）有优势。ConvNeXt（Liu 等 2022）照着 Transformer 的设计习惯把卷积网络改了一遍，在同样的数据上和它打成了平手：哪种结构更好，至今没有定论，很多系统是混着用的。Are convolution and recurrence obsolete? No. With little data, real-time demands or small chips, the convolutional prior is a bargain; when a system is always online and its memory must stay fixed, recurrence (and state-space models like Mamba) has the edge. ConvNeXt (Liu et al. 2022) reworked a convolutional network following the Transformer’s design habits and drew level with it on the same data: which architecture is better is still unsettled, and many systems mix them.
    • 扩散模型是一种主干吗？不是。扩散规定的是学什么（猜噪声）和怎么用（从噪声一步步去噪），里面的网络可以是 U-Net，也可以是 Transformer。Is a diffusion model a kind of backbone? No. Diffusion specifies what to learn (guess the noise) and how to use it (denoise step by step from noise); the network inside can be a U-Net or a Transformer.

    检查一下Check yourself

    一张 100 × 100 的灰度图，要输出一张同样大小的特征图（1 个通道）。用全连接层和用 3 × 3 卷积，各要多少个权重（不算偏置）？A 100 × 100 greyscale image should produce a feature map of the same size (1 channel). How many weights (not counting biases) does a fully connected layer need, and how many does a 3 × 3 convolution need?

    全连接：每个输出连所有输入，10000 × 10000 = 1 亿个。卷积：9 个。差了一千多万倍，省下来的就是"只看邻居、到处共用"这两个假设。Fully connected: every output connects to every input, 10000 × 10000 = 100 million. Convolution: 9. That is more than ten million times fewer, and the saving comes entirely from the two assumptions “look only at neighbours, share everywhere”.

    一个 30 层的普通网络，每层让梯度乘 0.8，传回第一层还剩多少？加了残差连接以后，为什么不会这样？In a 30-layer ordinary network where each layer multiplies the gradient by 0.8, how much is left when it gets back to the first layer? Why does this not happen with residual connections?

    0.830 ≈ 0.001。梯度是一路上局部斜率的乘积（第 1 步）。加了残差以后，每层的局部斜率是"1 + F 的斜率"，就算 F 的斜率很小，梯度也能沿着"1"那条路原样传回去。0.830 ≈ 0.001. A gradient is the product of the local slopes along the way (step 1). With residual connections, each layer’s local slope is “1 + F’s slope”, so even if F’s slope is tiny, the gradient can travel back unchanged along the “1” path.

    把一句话里的词随机打乱，不加位置编码的注意力层，输出会怎样？If you shuffle the words of a sentence at random, what happens to the output of an attention layer without position encoding?

    每个词得到的输出一点不变，只是跟着换了位置（第 5 步的交互）。它分不出"狗咬人"和"人咬狗"，所以必须加上位置编码。Each word’s output stays exactly the same and just moves along with the word (the interactive in step 5). It cannot tell “dog bites man” from “man bites dog”, which is why position encodings are essential.

    Stable Diffusion 里，哪部分是"主干"，哪部分是"扩散"？In Stable Diffusion, which part is the “backbone” and which part is the “diffusion”?

    主干是 U-Net（加上看文字的交叉注意力）。扩散是训练目标"猜噪声"，加上生成时"从噪声一步步去噪"的过程。把 U-Net 换成 Transformer（DiT、SD3），它照样是扩散模型。The backbone is the U-Net (plus the cross-attention to the text). The diffusion is the training objective “guess the noise” plus the generation process “denoise step by step from noise”. Swap the U-Net for a Transformer (DiT, SD3) and it is still a diffusion model.

    扩散模型生成时，为什么不能一步到位？Why can a diffusion model not generate in a single step?

    噪声最大时，同一个带噪声的样子可能来自任何数据，用平方误差学到的最好猜测，是所有数据的平均。一步到位，就落在这个平均上，它可能是一个根本不存在的样子，比如两种绕法的正中间，直直撞上树（第 6 步）。一步步走，每一步要平均的范围越来越小，最后才落到某一种具体的做法上。At the highest noise, the same noisy picture could have come from any data, and the best guess learned with squared error is the average of all the data. A single step lands on that average, which may be something that does not exist at all, such as the exact middle of two detours, straight into the tree (step 6). Going step by step, the range being averaged shrinks with every step until the result finally lands on one specific way of acting.
